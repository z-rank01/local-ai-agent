# 财务、规模与估值

每个数字保留主体、指标、期间、原单位、原值、披露时间和原文页码或位置。优先公司公告；第三方字段注明来源。冲突未解决时不放进图表或估值结论。

| 分析 | 核对 |
| --- | --- |
| 盈利 | 营收、归母净利润与扣非；合并净利润不能替代归母。首次解释术语 |
| 现金流 | 经营现金流净额不是客户回款额；结合应收账款、合同资产、现金收支，不能仅净额较高就判回款质量好 |
| 规模 | 跨期订单总额除年度营收只作规模参照；总额除期限是算术平均，不要求均匀分配，也不是实际确认收入 |
| 估值 | 价格日、股数、归母净资产及盈利期间配套；亏损PE不作正常比较，PB仅为账面参照 |
| TTM | 最近十二个月：上年全年 + 本年累计 - 上年同期；三项同主体同指标 |

调用现有股票字段/程序结果时沿用其证券、期间和计算口径。新增简单算式用容器 Decimal 计算，记录输入和公式；程序算对不代表经济推论正确。不建设新的估值规则或猜目标价。

## 从数字到判断：逐项核对前提

- 归母净利润是利润归属口径，不是可分红现金，也不等于股东实际收到的分红。经营现金流包括经营活动的现金收支，不能用“更难做出来”等话替代证据。
- 毛利率变化可能来自售价、成本或产品结构。未取得销量、单价及成本拆分时，不能据此断言“让价”“卖得少”或“不是卖得便宜”。
- 销售收现减少不等于回款变慢。先区分销售规模变化，再看应收周转、账龄和收款周期；这些资料不足就保留具体原因未知。
- 每个占比在正文中写清分母：总营业收入、主营业务收入、某分部收入不能互换。先用原值复算，再核对名称，不能用正确数字配错误标签。
- 当前市值使用未复权价格和对应时点有效股数。前复权历史价格、较早股数或净资产只能在说明假设与日期后作估算；口径无法核对时不下实际估值结论。
- 市盈率或市净率低于多少是数值；“便宜”是判断，需要历史、同行或明确假设支持。历史分红额除估算市值不等于承诺的未来股息率。

自查时找一个也能解释同一数字的其他原因。若现有资料无法区分原因，保留研究判断的条件，不把解释写成事实。仍可作出继续研究、等待验证或暂不关注的结论，说明依据及改变判断的条件。
