# 表格核对

先读取表头与少量数据，确认关联列、待核对数值列、单位、期间与币种；同名字段不能替代口径确认。不明确时只问影响匹配的关键问题。

使用自带 `scripts/reconcile.py` 做十进制精确比较，不让模型心算金额差异：

```text
python scripts/reconcile.py 左表.csv 右表.csv --key 单号 --columns 金额 数量 --output 工作区中的新结果.json
```

脚本支持 UTF-8（含 BOM）CSV 和 TSV，`--tolerance 0.01` 指定绝对容差；默认精确相等。输入原件不修改，已有输出拒绝覆盖。重复编号不擅自汇总，空值和非数字不当作零。带货币符号、千分位或百分号的字段须先确认转换口径，另存标准化副本并保留来源。

Excel 文件先通过当前可用工具读取并另存所需表页；无法读取时明确说明缺少的能力，不直接对二进制文件运行本脚本。回读 JSON，向用户解释差异条数、缺行、无法比较的条目，附结果路径。状态“存在待确认项”不能报告为全部一致。
