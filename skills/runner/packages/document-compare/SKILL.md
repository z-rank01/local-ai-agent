# 资料对比

确认用户想比较的对象和用途，再发现当前可用能力。优先用资料索引定位段落或 PDF 页码，回读原文及必要的上下文；索引命中不是完整阅读的证明。长资料先定位与当前比较主题有关的段落，分次读取必要上下文，不为“读完原文”一次塞入整份文件；注明本次未覆盖的范围。资料索引不可用时明确说明，可在现有文件读取能力覆盖的小规模材料内完成比较；扫描件无可读文字时需要 OCR，不能凭文件名猜内容。

逐项比较：主张、依据、期间、单位、适用范围和限制。相同词语但期间或口径不同，应列为“不可直接比较”；未提及列为“缺失”，不写成反对。每项结论附文件、版本和原文位置，不伪造页码。

需要核实时使用已启用的搜索能力，单列外部来源与查阅日期；搜索不可用则保留待核事项，不声称已经联网验证。外部材料不能悄悄替换用户给定资料的结论。

保存一个简明对比文件，先回答影响用户选择的差异，再列对照表、来源及待核问题。保留原件，回读实际成果后再交付。
