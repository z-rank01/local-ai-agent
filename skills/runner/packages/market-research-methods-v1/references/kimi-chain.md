# 产业链传导方法

| 问题 | 项目适配做法 |
| --- | --- |
| 边界 | 定义需求端、上游投入、中游制造、下游渠道及时间范围。 |
| 利润 | 逐环节问谁定价、谁承担库存和营运资本、成本能否转嫁、瓶颈在哪里。 |
| 公司映射 | 公司业务、供应关系、产能或客户关系须用公司公告、财报或可核对原文证明；行业文章只作背景。 |
| 反证 | 关注扩产、替代、需求落空、政策变化、价格传导失败及利润被其他环节攫取。 |
| 观察 | 给每条假设列可测指标、频率、原始来源；缺数据保留待核查。 |
