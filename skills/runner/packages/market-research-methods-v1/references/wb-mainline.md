# 市场主线方法

| 问题 | 项目适配做法 |
| --- | --- |
| 是否有主线 | 结合跨日催化、板块扩散、成交和行业基本面；单日脉冲只记为待验证。 |
| 热度与价值 | 区分事实增长、预期重估和纯情绪；高热度增加反证检查，不直接否决研究。 |
| 持续性 | 列出验证窗口、关键指标和失效条件；缺行情或资金证据时不臆测情绪周期。 |
| 公司关联 | 主线只提出待核查公司，不把题材分类或同涨证明为实际受益。 |
