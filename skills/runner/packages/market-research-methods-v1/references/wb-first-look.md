# 公司初看方法

| 问题 | 项目适配做法 |
| --- | --- |
| 公司身份 | 核对代码、市场、主营、收入构成和实际产业链位置。 |
| 为何现在 | 将公司直接公告与行业背景分开；催化不存在时保持观察。 |
| 经营变量 | 追踪收入、利润、现金流、产能、订单或客户中与假设相关的变量，注明期间。 |
| 分歧 | 说明支持、反证、估值口径与尚需核查的证据；缺值不能用形容词补齐。 |
| 交接 | 给 C05 的是待审研究速览，不是交易准入。 |

| 来源 | 版本 | 适用 | 不继承的宿主约束 |
| --- | --- | --- | --- |
