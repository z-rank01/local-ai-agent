# 每日简报方法

| 步骤 | 项目适配做法 |
| --- | --- |
| 核对时点 | 标记交易日、快照时点、休市与跨日区间；盘前和盘后的可得证据不同。 |
| 市场事实 | 指数、成交、涨跌分布与事件各标来源和日期；缺少板块、资金或海外数据时明确留空。 |
| 解释 | 每个重要变化说明“为何值得关注”、可能传导、反证和下一次可观察信号。 |
| 事件 | 标题只负责排队；读已核对原文后再解释。政策、行业、公司直接证据分开。 |
| 展示 | 重点可少量展示，后台已读范围、未读范围、失败日期都要保留。 |

| --- | --- | --- | --- |
