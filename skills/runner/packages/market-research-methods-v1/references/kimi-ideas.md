# 机会选题方法

| 问题 | 项目适配做法 |
| --- | --- |
| 选题入口 | 可从公开事件主题向公司推，也可从公司公告向行业反查；说明市场与时间范围。 |
| 初筛 | 候选仅是研究问题。按证据重要性与多样性安排核查，不用展示名额截断后台研究。 |
| 逐公司 | 区分主题关联、公司直接证据、财务与估值证据；每条关系标已证实或推断。 |
| 下步 | 每项给出最关键的补查问题和否定条件；证据不足可以没有速览。 |
| 门禁 | C05/D01 和人工账户确认按原规则执行，速览不能变成订单。 |
