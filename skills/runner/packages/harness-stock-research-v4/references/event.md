# 公告影响

读指定公告原文，记录公告日期、主体、金额、期限、条件和风险提示。相关后续公告另列日期，不能把旧公告状态当作今天已核实的状态。

中标、签约、履约、确认收入是不同阶段。原文“不确定”不能改为“有限”；尚未正式签约不直接证明法律效力；三年服务不证明本年没有收益。

分析事件怎样影响收入、成本、现金或风险，逐步写出必要条件。有披露依据才给具体幅度或年份。可用已核验年度营收作规模参照，但跨年总额不是当年新增收入。

最多列三项后续观察：正式合同和金额变化、实际履约/收入确认、回款或风险进展。不要编造披露日期、毛利率或法律期限。

Recipe判断记录：同一研究包含多个项目时，分别关联项目身份、公告日期、合同金额、收入确认、利润、付款结算及资金占用。不得把项目甲条款用于项目乙；历史状态保留观察日期。 将结论所依赖的原文/计算、条件与未解问题写入阶段成果，不能把字段完整当作判断成立。
