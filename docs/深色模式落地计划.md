# 深色模式落地计划

日期：2026-10-10。视觉来源：[归档原型](./原型/harness-a-dark-mode.html)，从桌面同名文件原样复制。本文件保存设计与验收方法；批次状态只维护股票仓库 `docs/计划.md`，具体证据见[实施记录](./记录/2026-10-10-深色模式.md)。

## 已确认的范围

| 项目 | 约束 |
| --- | --- |
| 外观 | 纯黑深色舞台；当前布局、交互与浅色配色保持；浅色既有对比度问题另行处理 |
| 主题 | 跟随系统 / 浅色 / 深色；默认与重置为跟随系统 |
| 数据 | 沿用 `local-ai-agent.appearance.v1`，保留字体、字号、行高、密度和阅读宽度；无效主题回退系统 |
| 范围 | 前端主题层、设置控件、验证脚本和文档；无新后端接口、数据库字段、依赖或原生标题栏定制 |
| 交付 | 用户已追加授权提交代码、原型和文档，在 `main` 提交；保留用户原有文档删除，不恢复旧前端计划；待实测清单不变 |

## 实施结构

| 层 | 处理 |
| --- | --- |
| 令牌 | `styles.css` 浅色 `color-scheme` 与深色覆盖；完整表面、文字、边框、语义色、阴影及石墨黑层级 |
| 语义引用 | `--link`、`--knob`、`--scrim`、`--card` 按原型用途引用；反色按钮独立 hover；代码卡、轨迹、阅读器始终深色 |
| 对比度 | 深色元信息、代码标题、模型选中行及小标签使用原型更亮文字阶梯；不改浅色颜色，不改变布局 |
| 初始化 | 页面 head 在 CSS/React 前解析偏好并写根元素主题；损坏或不可访问存储正常回退 |
| 运行期 | `lib/theme.ts` 解析实际主题；系统态监听媒体查询，手动态不跟随；卸载清理监听 |
| UI | 设置外观页顶部复用分段控件；原生按钮支持 Tab、Enter、Space，公开选中状态 |

## 验收方法与边界

| 项目 | 方法 |
| --- | --- |
| 离线 | `npm run test:theme --prefix apps/web`、typecheck、build；兼容旧数据、无效 JSON、不可用存储/媒体查询、监听清理和手动态隔离 |
| 浅色回归 | 固定会话、字体、1366×900；从当前提交的前端源快照构建基线，始终经现有 BFF 托管页面对照；不另启服务或数据库 |
| 深色视觉 | 实际计算样式检查文字 ≥4.5:1、大字和必要图标 ≥3:1；覆盖首屏、设置、工作台、技能展开/收起、模型弹层、代码和报告阅读器 |
| 布局 | 1920、1366、1024、720、560、360 六档；标题居中、技能折叠、横向溢出与工作台让位 |
| 在线 | 只通过 `启动.bat → start-daily.ps1`；股票相关验收使用已保存独立状态目录且 `worker=false`；不触发模型/股票任务 |
| 待实测 | 原生 `-Desktop` 展示、真实系统主题变化、首帧录制及原型同数据逐像素对照；自动化不可用时不得以构建结果替代 |

需要回退时只逆向撤销本轮具体主题改动，保留其它未提交内容和用户删除；不执行整库 `git restore`。完整令牌与施工规范见[UI设计笔记](./UI设计笔记.md)。
