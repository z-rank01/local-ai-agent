# 文档记录简则（AI 与人工协作者）

本规则适用于本仓库 docs。根目录 AGENTS.md、用户当前指示优先；IN 系列统一进度在股票仓库 docs/计划.md。

| 文档类型 | 放哪里 | 写法 |
| --- | --- | --- |
| 当前使用与排错 | [日常运行指南](./日常运行指南.md) | 表格列出入口、动作、结果与常见问题；避免旧路径 |
| 聊天侧模块与契约 | docs 根目录对应主题文件 | 先给 1～3 个简表；保留必要边界，具体实现细节链接到记录 |
| 验证场景 | [回归验证指南](./回归验证指南.md) | 用场景/操作/预期表；一次验收的证据单列记录 |
| 调查、联调、更新、历史快照 | [记录](./记录/README.md) 下的独立 Markdown | 按日期/主题命名；表格或短列表优先；写明当时状态 |
| IN 进度 | 股票仓库 docs/计划.md | 本仓库只链接，不另建完成清单 |

| 每次更新检查 | 要求 |
| --- | --- |
| 真实性 | 区分设计、已实现、离线检查、在线实测和人工验收；旧快照不冒充当前 |
| 结构 | 表格优先、段落简短；长日志、命令输出、来源清单移到记录 |
| 证据 | 写日期、任务号、提交、检查结果、剩余缺口与适用范围 |
| 链接 | 相对路径优先；移动文档后检查入站和出站链接 |
| 安全 | 不写入密钥、私有账户数据或完整聊天；遵守唯一启动入口、数据目录与退出路径 |
| 收尾 | 对应进度只更新股票仓库计划；检查 Markdown 表格和链接后再提交 |
