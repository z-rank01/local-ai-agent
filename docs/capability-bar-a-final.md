# 能力栏 A 方案 · 组件规范与落地计划

> 能力不是功能按钮，而是本次任务的上下文。A 方案用一条稳定的 40px 单行能力带，把“已经选择的能力”和“可以添加的能力”拆成两层：已选能力贴着输入框，完整能力库只在上浮层出现。

## 0. 结论卡

| 项目 | 结论 |
| --- | --- |
| 定稿方案 | A · 行内胶囊 |
| 设计状态 | 定稿，可进入实现 |
| 交互载体 | Composer 上方能力带 + 374px 上浮层 |
| 常驻高度 | 40px（触屏粗指针 52px） |
| 默认展示 | 前 2 项 + 数量摘要 |
| 主入口 | 唯一「能力」按钮，支持 `⌘K / Ctrl K` |
| 备选 | B 能力坞、C 指令面板仅保留为参考，不进入默认路径 |
| 原型 | `capability-bar-review.html` |

**一句话验收：** 在 320px 到 1440px 宽度下，能力栏始终保持单行、不换行、不横向滚动，添加或移除能力不会推动输入框位置。

## 1. 决策与边界

### 1.1 为什么是 A

- **输入优先。** 工作台的核心动作是写需求、看结果，能力栏不能持续占用垂直空间。
- **状态清楚。** 左侧是已选能力，右侧是唯一入口；两者视觉权重不同，用户不需要猜哪个是“已启用”。
- **可扩展。** 能力库不常驻，技能和插件数量增长时，栏高不变。
- **可回退。** 交互结构简单，出问题时可以退回现有能力入口，不需要迁移输入框结构。

### 1.2 相对现状的变化

| 维度 | 现状风险 | A 定稿 |
| --- | --- | --- |
| 入口 | 已选与可添加混在同一排 | 已选在左，唯一「能力」入口在右 |
| 高度 | 随名称与数量变化 | 固定 40px，不推动 Composer |
| 能力库 | 横向浏览，说明被压缩 | 374px 上浮层，可搜索与筛选 |
| 溢出 | 换行或横向滚动 | 前 2 项 + `+N`，单行 |
| 状态 | 选择与入口同权 | 胶囊 = 已选，浮层 = 可选 |

### 1.3 本次范围

- Composer 上方的能力带。
- 能力选择浮层：搜索、类型筛选、添加、移除、选中状态。
- 键盘、焦点、空状态、窄屏摘要。
- 与技能/插件注册表的数据适配。
- 灰度、回滚与验收。

### 1.4 非范围

- 技能/插件市场、详情页、安装/卸载。
- 推荐排序、智能补全、AI 推荐能力。
- 拖拽排序、批量管理、跨项目能力模板。
- B、C 方案的默认入口。

## 2. 术语与层次

| 术语 | 含义 |
| --- | --- |
| Capability | 技能与插件的统一上层概念 |
| Skill | 一套任务方法与工作流，例如「网页原型」「幻灯片」 |
| Plugin | 提供工具或槽位的能力，例如「Figma 导出」「Apple 设计系统」 |
| Selected | 当前任务已经挂载、会参与下一轮生成的能力 |
| Library | 可搜索、可筛选的完整能力集合 |

能力栏只负责三层，不承担管理职责：

1. **上下文层**：已选能力胶囊。
2. **动作层**：唯一的添加入口。
3. **选择层**：上浮的能力库。

管理、安装、权限与版本信息留在技能库/插件页面，不进入 Composer。

## 3. 组件解剖

```text
┌─ Composer ──────────────────────────────────────────────┐
│  [网页原型 ×]  [Apple 设计系统 ×]  +2        + 能力  ⌘K  │  40px
│  ┌───────────────────────────────────────────────────┐  │
│  │ 把首屏标题再收短，保留黑场和那一处蓝色。             │  │
│  │ 附件   OD Agent                         Ctrl ↵  ↑  │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 3.1 能力带

| 区域 | 规格 | 说明 |
| --- | --- | --- |
| 根容器 | 高 40px；左右内边距 3px；底部 6px | 桌面指针固定高度；粗指针提升到 52px，以容纳 44px 触控目标 |
| 已选区 | `flex: 1; min-width: 0` | 只放已选胶囊与 `+N` |
| 胶囊 | 高 28px；圆角 980px；内边距 0 6px 0 8px | 单行，不换行 |
| 胶囊间距 | 5px | 保持紧凑但不粘连 |
| 胶囊文字 | 10.5px / 500 / 1.2 | 当前原型值；工程若统一最小字号，需整组上调 |
| 胶囊图标 | 12px | 单色，不承担状态语义 |
| 移除符号 | 14px 圆形；hover/focus 出现 | 不默认显示，避免噪声 |
| 触发器 | 高 28px；圆角 7px；内边距 0 7px | 唯一入口 |
| 快捷键提示 | 8px mono；边框 1px | 窄屏隐藏 |
| 溢出摘要 | 高 26px；边框 1px；mono 8.5px | 例如 `+2` |

### 3.2 选择浮层

| 区域 | 规格 | 说明 |
| --- | --- | --- |
| 浮层 | 宽 374px；圆角 16px；边框 1px | 上浮，不做全屏抽屉 |
| 最大高度 | `min(418px, calc(100vh - 430px))` | 列表内部滚动 |
| 位置 | 触发点上方 8px；左对齐 | `transform-origin: bottom left` |
| 头部 | 13px 内边距；标题 14px Display | 说明“添加能力”与技能/插件差异 |
| 搜索 | 高 31px；圆角 8px | 自动聚焦；清空恢复全部 |
| 筛选 | 高 24px；圆角 6px | 全部 / 技能 / 插件 |
| 列表行 | 最小高 50px；圆角 9px | 图标 30px + 名称/描述 + 状态 |
| 行名称 | 10.5px / 500 | 单行 |
| 行描述 | 9px / 400 | 单行省略，完整描述通过 `title` |
| 类型标签 | 7.5px mono；边框 1px | 技能 / 插件 |
| 选择状态 | 21px 圆形；选中为深色填充 + 勾 | 不使用品牌蓝 |
| 底部提示 | 8.5px | 点击即可添加或移除 / Esc 关闭 |

### 3.3 与 Composer 的关系

- 能力带属于 Composer 的上下文区，不属于全局导航。
- 胶囊与输入框之间的间距固定为 6px。
- 浮层覆盖对话区，不改变 Composer 高度。
- 浮层关闭后，输入框、光标和滚动位置保持原样。

## 4. 视觉规范

### 4.1 Token 约束

- 颜色只使用项目设计系统 token：`--bg`、`--surface`、`--surface-warm`、`--fg`、`--fg-2`、`--muted`、`--border`、`--accent`、`--focus-ring` 等。
- 不新增颜色 token，不写裸 hex。
- 能力胶囊不使用品牌蓝填充。品牌蓝保留给发送按钮、主操作与焦点态。
- 不使用渐变、发光、彩色阴影或 emoji 图标。

### 4.2 关键颜色关系

| 元素 | 默认 | Hover | Focus |
| --- | --- | --- | --- |
| 胶囊背景 | `color-mix(in oklab, var(--fg) 5%, var(--bg))` | 9% | 保持背景，增加蓝色焦点环 |
| 胶囊文字 | `var(--fg-2)` | `var(--fg)` | `var(--fg)` |
| 胶囊图标 | `var(--muted)` | `var(--fg-2)` | `var(--fg-2)` |
| 触发器 | 透明 | `var(--fg)` 6% | 蓝色焦点环 |
| 列表行 | 透明 | `var(--surface)` | 行内焦点环 |
| 选中行状态 | `var(--fg)` 填充 + `var(--bg)` 勾 | 保持 | 保持 + 焦点环 |

对比度要求：正文与控件文字 ≥ 4.5:1；图标与边框 ≥ 3:1；hover 后文字不能变浅。

### 4.3 字体与文案

- 能力名：10.5px / 500；不换行；最长显示宽度 190px，超出省略，`title` 与 `aria-label` 保留全名。
- 能力描述：9px / 400，单行；保持一句话，不堆叠版本号。
- 类型标签：技能 / 插件，不写“官方”“推荐”等等级词，除非注册表提供可信来源。
- 数字只用于真实状态，例如 `+2`、`2 项`；不展示虚构使用量或热度。
- 文案避免“立即解锁”“超级能力”等营销语。

## 5. 状态模型

```text
closed
  │ click / ⌘K / Ctrl K
  ▼
open ──搜索/筛选──▶ open(filtered)
  │ add / remove（乐观更新）
  ▼
open(updated) ──Esc / 点击外部 / 关闭──▶ closed
  │ 请求失败
  ▼
open(error) ──重试──▶ open
```

| 状态 | 触发 | 视觉 | 行为 |
| --- | --- | --- | --- |
| Closed | 默认 | 40px 能力带 | 只显示已选与入口 |
| Open | 点击能力 / `⌘K` | 浮层 180ms 上浮 | 聚焦搜索框 |
| Loading | 能力库请求中 | 3 行骨架，保持浮层宽度 | 搜索禁用，Esc 可关闭 |
| Empty | 当前任务未选能力 | 左侧“尚未挂载能力” | 入口仍可用 |
| No results | 搜索无结果 | 列表空状态 + 清除搜索 | 不关闭浮层 |
| Error | 加载/写入失败 | 错误文案 + 重试 | 保留已有选择，回滚乐观更新 |
| Disabled | 权限或任务运行中 | 降低对比度，禁用指针 | 不打开浮层 |
| Overflow | 已选超过 2 项 | 前 2 项 + `+N` | 打开浮层可管理全部 |

### 5.1 添加与移除

1. 点击未选行：立即加入已选集合，行变为选中，保持浮层打开。
2. 点击已选行：立即移除，行恢复未选，保持浮层打开。
3. 点击胶囊：移除该项；焦点移动到下一个胶囊；没有下一项时回到触发器。
4. 写入失败：回滚集合，显示错误 toast，焦点回到原行。
5. 不允许重复 id；以 id 去重，重复添加视为 no-op。

### 5.2 空状态与错误

- 空能力：`尚未挂载能力`，不占据额外高度。
- 搜索无结果：`没有找到匹配的能力`；提供清除入口（原生 search 清除或独立按钮）。
- 加载失败：`能力加载失败` + `重试`；保留已选能力。
- 权限不足：`当前项目不可用`；不显示添加入口。

## 6. 交互规范

### 6.1 打开与关闭

- 点击触发器打开；再次点击关闭。
- `⌘K` / `Ctrl K` 打开或关闭。
- 点击浮层外部关闭。
- `Esc` 关闭并把焦点还给触发器。
- 关闭时清空搜索与筛选，下一次打开回到“全部”。

### 6.2 搜索与筛选

- 搜索范围：名称、类型、描述；大小写不敏感。
- 本地搜索：能力数 ≤ 100 时即时过滤，无网络请求。
- 远程搜索：> 100 时由服务端搜索，输入防抖 150ms；请求竞态只接受最后一次结果。
- 筛选：全部 / 技能 / 插件；与搜索叠加。
- 无结果时不关闭浮层，焦点留在搜索框。

### 6.3 键盘

| 按键 | 行为 |
| --- | --- |
| `Tab` | 在浮层内循环：关闭 → 搜索 → 筛选 → 列表行 |
| `Shift + Tab` | 反向循环 |
| `↓` / `↑` | 在搜索结果中移动焦点 |
| `Enter` | 切换当前行的选中状态 |
| `Esc` | 关闭浮层，焦点回到触发器 |
| `⌘K` / `Ctrl K` | 打开/关闭 |
| `⌘ / Ctrl + Enter` | 发送（Composer 现有能力，不由能力栏接管） |

### 6.4 焦点管理

- 打开后焦点进入搜索框。
- 浮层打开期间焦点不离开浮层。
- 从列表行添加/移除后，焦点留在原行。
- 从胶囊移除后，焦点移动到下一个胶囊；没有则回到触发器。
- 关闭后焦点回到触发器；如果触发器不可见，回到 Composer。

### 6.5 动效

| 动作 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| 浮层打开 | 180ms | `cubic-bezier(0.28, 0, 0.22, 1)` | 透明度 + 上移 7px + 0.985 缩放 |
| 浮层关闭 | 180ms | 同上 | 不做弹跳 |
| 胶囊加入 | 180ms | 同上 | 0.96 → 1，透明度 0 → 1 |
| 胶囊移除 | 立即 | — | 不保留空位，不改变栏高 |
| Hover | 150ms | 同上 | 只动背景、边框或位置 |

- `prefers-reduced-motion: reduce` 时全部动效降到 0.01ms。
- 不使用 height 动画推动 Composer；能力带高度恒定。

## 7. 可访问性

### 7.1 语义

| 元素 | 角色 / 属性 |
| --- | --- |
| 已选区 | `role="group"` + `aria-label="已选能力"` |
| 胶囊 | `<button>`；`aria-label="移除能力：{name}"`；`title` 同名 |
| 触发器 | `<button>`；`aria-haspopup="dialog"`；`aria-expanded`；`aria-controls`；`aria-label="添加或管理能力"` |
| 浮层 | `role="dialog"`；`aria-modal="false"`；`aria-labelledby` |
| 搜索 | `<input type="search">` + `aria-label` |
| 筛选 | `role="tablist"`，每个 tab 有 `aria-selected`、`aria-controls` |
| 列表行 | `<button>`；`aria-pressed` 表示是否已选 |
| 结果反馈 | `role="status"` + `aria-live="polite"` 的 toast |

### 7.2 对比度与焦点

- 普通文字 ≥ 4.5:1；大字号文字与图标 ≥ 3:1。
- 所有可聚焦元素使用 `:focus-visible` 蓝色焦点环，不能只靠颜色变化。
- Hover 不能把文字变得更浅；选中态不能只靠图标颜色区分。
- 触控设备上主要控件最小 44px；能力胶囊在粗指针设备上高度提升到 44px。

### 7.3 屏幕阅读器

- 添加/移除后播报：`已挂载「网页原型」` / `已移除「Apple 设计系统」`。
- 浮层打开时播报标题与“可搜索能力”。
- 搜索结果变化时播报数量（只播报真实结果数）。
- 不使用 `aria-live` 播报每一次键盘移动，避免噪声。

## 8. 响应式与溢出

| 宽度 | 行为 |
| --- | --- |
| ≥ 921px | 展示完整胶囊、图标、`⌘K` 提示 |
| 541–920px | 保留 2 项 + 数量；触发器保留文字 |
| ≤ 540px | 隐藏快捷键提示；浮层宽度改为 `calc(100vw - 20px)`；能力坞/指令面板参考版收起 |
| ≤ 380px | 胶囊最大宽度 124px；名称省略，`title` 保留全名 |

- 能力带永远单行，禁止 `flex-wrap`。
- 不使用横向滚动容器。
- 超过 2 项时只显示前 2 项与 `+N`；完整列表在浮层里。
- 浮层最大高度随视口收缩，列表内部滚动；打开时不能遮住输入框。
- 320px 是最低支持宽度；桌面指针下保持 40px 栏高，触屏粗指针下提升到 52px 并保持可点击触发器。

## 9. 数据契约

### 9.1 类型

```ts
export type CapabilityKind = 'skill' | 'plugin';
export type CapabilityStatus = 'ready' | 'loading' | 'unavailable';

export interface CapabilityItem {
  id: string;
  name: string;
  kind: CapabilityKind;
  description: string;
  icon: string;
  status?: CapabilityStatus;
  source?: 'official' | 'workspace' | 'community';
}

export type ToggleCapability = (
  item: CapabilityItem,
  selected: boolean
) => void | Promise<void>;
```

### 9.2 组件 API

```ts
interface CapabilityBarProps {
  selected: CapabilityItem[];
  library: CapabilityItem[];
  maxVisible?: number;             // 默认 2
  loading?: boolean;
  disabled?: boolean;
  onToggle: ToggleCapability;
  onSearch?: (query: string) => void;
  onFilterChange?: (kind: 'all' | CapabilityKind) => void;
  onOpenChange?: (open: boolean) => void;
}
```

实现约定：

- `selected` 与 `library` 由父级控制；能力栏不直接请求注册表。
- 组件内部管理浮层开关、搜索词、筛选、焦点；对外只发语义事件。
- 添加/移除采用乐观更新；`onToggle` 失败时父级返回错误，组件回滚并提示。
- 同一 `id` 不重复；顺序按用户添加顺序，v1 不支持拖拽排序。
- 新任务默认空选择；已存在任务从任务状态恢复；不要做全局默认挂载。原型示意的是“任务中已挂载两项能力”的状态，不是新任务初始态。
- 选择范围是“当前任务/会话”，不是全局偏好；全局收藏属于后续能力管理页。

### 9.3 数据与排序

- 能力库排序：最近使用（最多 3 个）→ 其余按注册表稳定顺序。
- 搜索：本地优先；超过 100 项再走服务端。
- 不可用能力保留在列表中但禁用，说明原因；不静默消失。
- 图标使用注册表返回的 icon key，映射到本地 SVG；不回退到 emoji。
- 能力名称过长时只做视觉省略，数据层保留完整名称。

### 9.4 事件

| 事件 | 触发 | 载荷 |
| --- | --- | --- |
| `capability_bar_open` | 打开浮层 | `{ source: 'click' \| 'shortcut' }` |
| `capability_add` | 选中能力 | `{ id, kind }` |
| `capability_remove` | 移除能力 | `{ id, kind }` |
| `capability_search` | 搜索提交/停顿 | `{ queryLength, resultCount }` |
| `capability_filter` | 切换筛选 | `{ kind }` |
| `capability_empty` | 无结果 | `{ queryLength, kind }` |
| `capability_error` | 加载/写入失败 | `{ stage, errorCode }` |

不要在埋点里上报完整搜索词；只上报长度与结果数。

## 10. DOM 与 CSS 接入

原型类名可直接映射，但接入时必须做作用域隔离，避免 `.cap-chip`、`.cap-add` 这类通用名污染全局。

| 原型类名 | 建议工程类名 | 作用 |
| --- | --- | --- |
| `.capbar-a` | `.od-capability-bar` | 40px 根容器 |
| `.cap-selected` | `.od-capability-bar__selected` | 已选区 |
| `.cap-chip` | `.od-capability-bar__chip` | 已选胶囊 |
| `.cap-add` | `.od-capability-bar__trigger` | 唯一入口 |
| `.cap-popover` | `.od-capability-popover` | 374px 浮层 |
| `.cap-row` | `.od-capability-row` | 能力行 |
| `.cap-state` | `.od-capability-row__state` | 选中状态 |

实现要求：

- 浮层使用绝对定位，锚定 Composer；如果父容器有 `overflow: hidden`，改为 portal 到 `body` 并按触发器位置计算。
- 浮层和 Composer 的 z-index 分离，避免被对话滚动区裁剪。
- 组件样式从设计系统 token 读取，不复制 token 值。
- 不使用内联颜色；尺寸可用组件级变量或常量。
- 不引入第三方弹层库，除非现有工程已统一使用；如引入，保留相同键盘与焦点行为。
- 组件卸载时清理 `keydown`、`pointerdown`、定时器与请求竞态。

## 11. 落地计划

> 粗估以 1 名前端 + 1 名设计 + QA 协作为基准，需在排期会上按实际代码库确认。

| 阶段 | 产出 | 责任 | 粗估 | 退出条件 |
| --- | --- | --- | --- | --- |
| 0. 冻结与映射 | 能力 id 映射表、旧入口清单、埋点表 | 设计 + 前端 | 0.5 人日 | 所有旧技能/插件有明确映射 |
| 1. 组件骨架 | `CapabilityBar`、`CapabilityPopover`、状态与样式 | 前端 | 1 人日 | 独立页面可完成添加/移除/搜索/筛选 |
| 2. 数据接入 | 注册表 adapter、任务级选择状态、搜索、错误回滚 | 前端 + 平台 | 1.5 人日 | 真实数据下选择可恢复，失败可回滚 |
| 3. 可访问性与 QA | 键盘、焦点、屏幕阅读器、320/1440、reduced motion | 前端 + QA | 1 人日 | P0 验收清单全部通过 |
| 4. 灰度与收口 | feature flag、内部试用、监控、旧入口下线 | 产品 + 前端 | 0.5 人日 | 无 P0 回归，可全量 |

**关键路径：** 数据映射 → 组件接入 → 可访问性回归 → 灰度。阶段 1 与阶段 2 可以部分并行，但真实数据未通前不要放量。

### 11.1 Feature flag

建议开关名：`workbench.capability-bar-a`。

- 关闭时：保留现有能力入口，不影响已有任务。
- 打开时：Composer 使用 A 能力带，读取同一份任务级选择。
- 灰度顺序：内部账号 → 设计/研发团队 → 小范围项目 → 全量。
- 回滚：关闭开关，保留数据；已选能力 id 仍可由旧入口读取。

**依赖清单：**

- 技能/插件注册表能提供稳定的 `id`、`name`、`kind`、`description` 与 `icon`。
- 任务状态可读写 `selectedCapabilityIds`，并有旧字段的一次性迁移方案。
- 图标映射表与统一占位图标已就绪。
- Feature flag 与埋点管线可用。
- 设计系统 token 已在目标应用加载；组件不复制色值。

### 11.2 迁移步骤

1. 盘点现有技能/插件入口、字段、权限与选择状态。
2. 建立 `CapabilityItem` 映射；缺少 icon 的能力使用统一占位图标，不生成新图。
3. 在任务状态中读写 `selectedCapabilityIds`；与旧字段做一次性迁移。
4. 接入搜索与筛选；先本地，后远程。
5. 加入键盘与焦点管理。
6. 打开 flag 做内部 dogfood。
7. 观察错误、空结果、移除失败；修复后放量。
8. 稳定一个版本后移除旧入口，保留回滚开关一个版本。

### 11.3 发布门槛

- P0 验收清单全部通过。
- 320px / 375px / 768px / 1024px / 1440px 无横向滚动、无遮挡、无布局跳动。
- 键盘可完成“打开 → 搜索 → 添加 → 移除 → 关闭”全流程。
- 屏幕阅读器可读出已选状态、添加/移除结果和空状态。
- 关闭 localStorage 或请求失败时，界面仍可用且不丢失已有选择。
- 能力选择与任务状态一致；刷新后恢复；新任务为空。
- 埋点无完整搜索词、无用户输入原文。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 浮层被 Composer 容器裁剪 | 内容不可见 | 父级 overflow 检查；必要时 portal + 触发器定位 |
| 能力注册表字段不一致 | 空名称/破图 | adapter 兜底；缺 icon 用统一占位；不可用项禁用 |
| 选择状态丢失 | 用户重复添加 | 任务级持久化；失败回滚；刷新恢复 |
| 搜索请求竞态 | 结果错乱 | 只接受最后一次请求；请求可取消 |
| 能力增长导致列表过长 | 搜索困难 | 本地/远程搜索；最近使用置顶；不做无限平铺 |
| 键盘焦点丢失 | 无法操作 | 行内焦点恢复；Esc 回触发器；Tab 循环 |
| 窄屏溢出 | 页面横向滚动 | 2 + N 摘要；固定栏高；320px 回归 |
| 旧能力入口并存 | 状态不同步 | 同一份任务状态；flag 灰度；一版后清理 |

## 15. 未决问题

1. **选择范围**：当前假设为“任务/会话级”。若产品要求跨任务保留，需要新增“项目级默认能力”概念，不能直接复用本组件。
2. **选择上限**：前端不设硬上限；若注册表有配额，以服务端返回为准，并在浮层底部提示。
3. **最近使用来源**：v1 使用本地最近记录；是否改为账号级同步，需要平台确认。
4. **不可用能力**：当前设计为保留并禁用；是否在切换模型时自动降级，需要 Agent 侧确认。
5. **多选批量操作**：不在 A 方案范围；如需要，另开交互评审。
