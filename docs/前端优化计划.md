## 3. 主题令牌方向（U2 落地）

现代 harness 浅色体系，令牌一次定义于 `styles.css :root`：

| 组 | 令牌 | 方向 |
| --- | --- | --- |
| 表面 | `--bg / --surface / --surface-soft / --surface-inset` | 暖白底、白面、暖灰陷层；废弃失效的 `--panel` 与近似暖白硬编码 |
| 线条 | `--line / --line-strong` | 两级暖灰细线，替换 55 处裸 `rgba()` 边框 |
| 文字 | `--text / --muted / --faint` | 正文 ≈12:1、灰 ≈5.3:1、弱提示仅装饰 |
| 强调 | `--accent / --accent-soft / --accent-strong` | 紫系 `#5f5bda` 统一；删除残留蓝（约 70 处）与绿 |
| 语义 | `--ok / --warn / --danger` + `-soft` 底 | 状态 pill 恢复绿/黄/红色差 |
| 阶梯 | `--space-1..6`、`--radius-sm/md/lg`+pill、`--text-xs..xl`、`--elev-1/2/3`、`--ring-focus` | 替换 16 种字号/16 种圆角/50 种 padding/29 条裸阴影 |
| 动效 | `--dur-1/2/3`(120/160/240ms)、`--ease-standard` | 全界面唯一时长来源 |

1. `:root` 按第 3 节重写；`--sidebar-width/--inspector-width` 单一定义（删 300/360/260 三处回退）。

9. 行尾统一 CRLF、书写风格统一（不引 Prettier/stylelint 新依赖，规则写入设计笔记）。
