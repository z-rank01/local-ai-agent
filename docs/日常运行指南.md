# 日常运行指南

## 启动

首次安装完成后，在 local-ai-agent 根目录运行：

```powershell
.\scripts\start-daily.ps1
```

浏览器会打开 <http://127.0.0.1:5173>。脚本启动工具容器、聊天后端和 Web；股票后台与任务执行按上次保存的开关恢复。顶部选择模型；使用云端模型不要求 Ollama，使用本地模型时需确保 Ollama 可用。

仅需聊天与服务控制、暂不使用容器工具时，可加 `-SkipTools`。文件、Python 等工具仍需工具容器运行。首次安装或升级依赖见[部署指南](../本地AI-Agents部署流程.md)。

## 使用股票服务

在右侧“股票服务”检查连接与任务状态。首次使用或更换位置时，展开“连接配置”：

| 项目 | 本机日常设置 |
| --- | --- |
| 股票仓库路径 | `D:\Stock_Agent_Workspace` |
| 状态目录 | `simulation` |
| 端口 | `8765` |

保存后点击“开启股票后台”。路径可按安装位置调整；状态目录必须位于股票仓库内。修改连接配置前先关闭股票后台，核对账户后再开启。

- **只聊天**：保持股票后台关闭，聊天和通用工具可独立使用。
- **查看账户与已有研究**：开启股票后台，任务执行保持暂停；排队任务不会开始，暂停不会取消已有任务。
- **运行研究和日常任务**：确认业务模式后点击“开启任务执行”。恢复模式先做恢复核对，正常模式按已有任务和预算规则执行。

连接与开关会保存，下次启动继续沿用。若不希望下次自动执行任务，退出前先暂停任务执行。

## 离线后恢复

1. 开启股票后台，查看业务模式、已核对日期和“恢复与待办”。
2. 需要恢复时开启任务执行，观察逐日记录；失败后先处理显示的问题，再点击“补跑 / 重试恢复”。暂停或重启后会继续未完成步骤。
3. 核对恢复摘要及待办。可在“人工操作”输入“帮助”“账户”“权益待办”，按返回的说明处理。
4. 满足条件后点击“核对并恢复运行”，阅读确认提示，再点击“确认恢复”。如果暂不运行日常任务，先暂停任务执行再确认。

历史资料缺失、权益疑点或模型结果不明时，按界面原因核查；不要手动修改数据库状态跳过阻塞。恢复补采不代表离线期间已实时监控；新订单仍需逐笔确认。

## 暂停与退出

- **暂停任务执行**：停止领取下一任务，当前任务继续收尾。“正在收尾”期间等待完成。
- **只关闭股票后台**：点击一次“关闭股票后台”，按钮显示“正在关闭股票后台…”，退出后自动显示“后台未运行”，聊天继续可用。若提示任务仍在收尾，等待后再关闭。
- **退出整个应用**：先完成任务收尾，再点击 Web 的“退出前端与后端”。仅关闭浏览器标签不会停止后台。需要停止工具容器时，在仓库根目录运行 `docker compose stop`；Docker Desktop 与 Ollama 按需自行退出。

再次使用时运行同一启动脚本。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 9510 被其他启动模式占用 | 在旧 Web 完成任务收尾并退出前后端，再运行日常脚本；不要同时运行多种启动脚本。 |
| 股票后台无法启动 | 检查仓库路径、状态目录、端口和股票 Python 环境；查看 `data/logs/stock-service.err.log`。 |
| 股票后台在线，任务没有推进 | 先查任务执行是否暂停，再查业务模式与恢复待办。 |
| 聊天后端或页面未就绪 | 查看 `data/logs/daily-bff.err.log`、`data/logs/daily-web.err.log`；安装问题见部署指南。 |
| 从旧隔离入口切换后看不到对话或文件 | 日常入口使用 `.env` 配置的数据路径；旧隔离数据仍在 `data/in1`，未自动迁移或删除。 |
