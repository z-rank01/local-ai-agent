# 日常运行指南

本机唯一入口是仓库根目录的 `启动.bat`。关闭页面约 15 秒后自动退出全部服务；也可点页面“退出”。

| 场景 | 操作 | 核对点 |
| --- | --- | --- |
| 启动 | 双击 `启动.bat`（等价于运行 `scripts/start-daily.ps1`） | 自动打开 `http://127.0.0.1:9510`；重复启动只打开浏览器 |
| 模型 | 页面顶部选择；密钥在“模型设置”保存 | 云模型无需 Ollama；启动器从已连接股票仓库配置读取 Ollama 回环端口，本地模型与事件分析共用该服务 |
| 云端工作区授权 | “模型设置”里两个独立开关：允许云端**读取**当前工作区文件 / 允许云端**写入与执行** | 读取授权只给 32 个只读工具（列目录、读文件、联网、历史会话、股票报告）；写入与执行（改文件、跑代码/命令、提交）另开关；关闭读取会一并撤销写入。本地模型不需要授权 |
| 联网搜索 | 右栏“技能”开关 | 开启后可搜索和读网页；关闭会停止搜索容器 |
| 研究方法 | 在已有会话的右栏“技能”选择“自动编排”或一种方法 | 选择保存在该会话；仅影响后续解释和明确提交的新研究，旧报告与自动日程不变 |
| 股票 | 右栏“股票技能”开关 | 后台由**启动器**在启动时拉起（就绪后自动恢复任务执行）；页面开关只负责**停止**，要重新启动请重新双击 `启动.bat` |
| 持仓监督 | 股票技能面板“持仓监督” | 查看待核查原因、报告与缺失项；订单草案仍需人工审查 |
| 每日市场简报 | 股票技能开启且模式为正常运行时，在 Web 对话说“看看每日市场简报” | 空仓可用；行情取最近交易日，资讯从上次交易日之后核对至当前日；读到正文的少量事件有本地 AI 解读，正文或模型失败会列缺口 |
| 刷新市场简报 | 在同一会话明确说“刷新每日市场简报”，完成后说“看看每日市场简报” | 新建版本并重新取数；旧报告仍可查；后台失败重试最多两次且有间隔 |
| 追问公开证据 | 找到已有简报后询问某事件、公司或报告页 | 模型可按事件续读原文位置与缺口；只有页映射确认时才说明该页具体事件，完整报告仍在本地附件 |
| 解释报告正文 | 在已授权云端读取工作区的会话里读一份报告 | 该轮模型**直接读到所请求页的正文**，可以解释页内内容，引用数字须与正文一致；未授权时只给版本元信息，模型不得声称已读 |
| 退出 | 点“退出”或关闭页面 | 股票任务先收尾，再停聊天服务与工具容器 |

| 股票首次连接配置 | 本机值 |
| --- | --- |
| 仓库路径 | `D:\Stock_Agent_Workspace` |
| 状态目录 | `simulation` |
| 端口 | `8765` |

连接配置在“股票技能 → 高级管理”。只聊天时可保持股票技能关闭。开启股票技能会按已有任务和预算规则执行；暂不运行任务时，在“高级管理”暂停任务执行。

## 离线后恢复

| 步骤 | 页面操作 | 注意 |
| --- | --- | --- |
| 1 | 开启股票技能，查看业务模式、已核对日期及“恢复与待办” | 先识别缺口与阻塞 |
| 2 | 按提示补跑或重试恢复，观察逐日记录 | 失败先处理原因；暂停或重启后可续未完成步骤 |
| 3 | 核对恢复摘要及待办；在“人工操作”输入“帮助”“账户”或“权益待办” | 历史补采不等于离线期间实时监控 |
| 4 | 点“核对并恢复运行”，阅读提示，再点“确认恢复” | 暂不执行日常任务时先暂停；新订单仍需逐笔确认 |

历史数据缺失、权益疑点或模型结果不明时，按界面原因核查，不手动改数据库状态绕过阻塞。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 浏览器未自动打开 | 手动打开 `http://127.0.0.1:9510`；若仍不可用，查看 `data/logs/daily-bff.err.log` |
| 9510 已占用 | 检查旧页面与服务；从旧页面退出或关闭后等约 15 秒再启动 |
| 股票技能启动失败 | 后台由**启动器**启动：重新双击 `启动.bat`（页面开关只负责停止）。启动器第 3 步会打印 `[OK] started on 127.0.0.1:8765`；失败看 `data/logs/stock-service.err.log` |
| 股票日志报 `unable to open database file` 或 `readonly database` | 先清 WAL 锁文件：退出整个栈后删掉状态目录的 `state.sqlite-shm` 与 `state.sqlite-wal`（**不要碰 `state.sqlite`**），再重新启动 |
| 股票任务未推进 | 检查“高级管理”的任务暂停状态、业务模式和恢复待办 |
| 联网搜索启动失败 | 检查 Docker；首次拉取镜像可能需要等待 |
| 关闭页面后仍运行 | 等约 15 秒；检查 `.env` 中 `AUTO_EXIT_ON_CLOSE` 是否为 `false` |
| 新字段/新行为不生效 | 多半是进程没换代码：`config/tools/*.yaml`、`core/**`、`bff/**` 改了要**重启聊天后端**；`config/prompts/**` 同样。容器不改代码，只换 YAML 时不需要重建 |
| 工具参数像是被忽略 | 改过 `skills/**`（容器内代码）却没重建镜像：用 `.\scripts\start-daily.ps1 -Build`。自查最快：`Invoke-RestMethod http://127.0.0.1:9101/openapi.json` 看该工具的请求字段是否含新参数 |
| 页面是旧界面 | 改过 `apps/web/**` 后要 `npm run build --prefix apps/web`，再刷新页面（Ctrl+F5） |

改代码后各自怎么生效，见仓库根目录 `AGENTS.md` 的「改完代码后怎么让它生效」。

更多操作细节与原始说明见[历史原稿](./记录/日常运行指南-原稿.md)。
