# 日常运行指南

> 更新：2026-09-15（单一入口改造）。每天只需记住一件事：**双击 `启动.bat`**，用完**关闭页面**即可。

## 启动

双击仓库根目录的 **`启动.bat`**（或运行 `.\scripts\start-daily.ps1`）。脚本启动工具容器、聊天服务并自动打开浏览器（<http://127.0.0.1:9510>）。已在运行时重复执行只会打开浏览器。

顶部选择模型；使用云端模型不要求 Ollama，使用本地模型时需确保 Ollama 可用。

## 技能开关（右栏）

| 技能 | 怎么用 |
| --- | --- |
| **联网搜索** | 右栏"技能"面板一键开启/关闭。开启后模型可联网检索与读网页；关闭即停掉搜索容器。开关保存，重启沿用。 |
| **股票技能** | 右栏"股票技能"面板一键开启/关闭。开启=启动股票后台并注册股票工具；关闭=停止股票后台（聊天不受影响）。首次使用需先在"高级管理 → 连接配置"保存股票仓库设置： |

| 项目 | 本机日常设置 |
| --- | --- |
| 股票仓库路径 | `D:\Stock_Agent_Workspace` |
| 状态目录 | `simulation` |
| 端口 | `8765` |

- **只聊天**：保持股票技能关闭，聊天和通用工具可独立使用。
- **查看账户与已有研究**：开启股票技能；排队任务不会开始。
- **运行研究和日常任务**：开启股票技能即默认开始任务执行（恢复模式先做恢复核对，正常模式按已有任务和预算规则执行）；不想让任务自动执行时，在"高级管理"里"暂停任务执行"。
- 退出前若不希望下次自动执行任务，先在"高级管理"里"暂停任务执行"。

## 离线后恢复

1. 开启股票技能，业务模式、已核对日期和"恢复与待办"显示在面板里（展开"高级管理"）。
2. 需要恢复时在"高级管理"开启任务执行，观察逐日记录；失败后先处理显示的问题，再点"补跑 / 重试恢复"。暂停或重启后会继续未完成步骤。
3. 核对恢复摘要及待办。可在"人工操作"输入"帮助""账户""权益待办"，按返回的说明处理。
4. 满足条件后点"核对并恢复运行"，阅读确认提示后再点"确认恢复"。暂不运行日常任务时，先暂停任务执行再确认。

历史资料缺失、权益疑点或模型结果不明时，按界面原因核查；不要手动修改数据库状态跳过阻塞。恢复补采不代表离线期间已实时监控；新订单仍需逐笔确认。

## 退出

- **点页面"退出"**：股票任务先收尾，随后聊天服务与工具容器全部停止，页面显示"已停止运行"。
- **直接关闭页面**：约 15 秒后自动执行同样的退出（股票正在收尾时会等它完成）。
- 重新使用：再次双击 `启动.bat`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击后浏览器没自动开 | 手动打开 <http://127.0.0.1:9510>；若打不开看 `data/logs/daily-bff.err.log` |
| 提示 9510 被占用 | 有旧服务在运行：从页面"退出"或关闭旧页面等待 15 秒，再双击启动 |
| 股票技能开不了 | 先保存"高级管理 → 连接配置"；检查股票 Python 环境；看 `data/logs/stock-service.err.log` |
| 股票技能已开启，任务没推进 | 看"高级管理"里任务执行是否暂停、业务模式与恢复待办 |
| 联网搜索开启失败 | 确认 Docker 在运行；重试一次，首次拉取搜索镜像需等待 |
| 关闭页面后服务还在 | 等待约 15 秒；仍不行检查 `.env` 的 `AUTO_EXIT_ON_CLOSE` 是否被改为 false |
