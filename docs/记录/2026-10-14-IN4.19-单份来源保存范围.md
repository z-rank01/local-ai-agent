# IN4.19：单份来源保存范围

| 复现 | 实际情况 |
| --- | --- |
| 原公告任务 | 公司聚合目录3529条、10个原文地址；目标中标公告仅保存1段1259字 |
| 旧读取范围 | 工具只有事件总数与聚合游标，不能据它判断某个URL的保存原文是否已经收到；不证明材料未读或缺数据 |
| 修改选择 | 现有读取增加来源级覆盖元数据，不新增工具、参数、来源请求或入口，原文顺序、分页与旧游标不变 |

| 实现 | 约定 |
| --- | --- |
| 股票侧 | source_coverage只列本页实际涉及且沿原外发地址规则的原文URL；保存段数、字符数及规范化原文指纹对应同一来源 |
| 原文与字段 | 只统计ORIGINAL_TEXT／PEER_ORIGINAL_TEXT，财务字段、模型推断及条件计算不凑全文覆盖；重复标识歧义仅剔除该来源元数据 |
| 聊天侧 | 依实际回执按同引用／事件／URL／快照合并，反复读同一页不增加覆盖；跨引用或不同快照不拼接凑完整，指纹不符保留未核对状态 |
| 当前模型输入 | 新读取结果在下一次模型请求前进入范围索引，不等待最终回答失败后才补索引；原始回执和原文不改，完全相同记录仅内部去重 |
| 范围含义 | 只证明当前保存快照收到的范围，不证明网站／PDF完整采集、最终综合或研究问题完成；旧回执没有范围元数据不证明没读过 |
| 缺失判断 | 不放宽确定缺失断言门槛；在保存原文范围未见条款，不等于现实中没有计划。法律效力与经营结论仍须独立依据 |
| 授权与展示 | 复用原Broker引用及云读开关；新增仅公开地址、计数和指纹。普通正文不用内部状态或哈希，不改报告排版与UI入口 |

| 验证 | 结果 |
| --- | --- |
| 股票侧 | 28项来源范围／财务／旧游标回归通过，10项原脱敏门通过；首次1项夹具错误要求云端保留空日期，改按旧投影逐项对照后通过 |
| 聊天侧 | 71项回归通过，含实际下一步模型视图、跨页反证、跨引用／版本隔离、原记录与来源读取兼容 |
| 真实保存数据 | 首页2个来源范围可验证，目标公告1段1259字已在该页；除新元数据外，旧投影与游标逐项相同，财务年度字段页不产生原文覆盖信息 |
| 副作用 | 0模型调用、0工具调用、0数据库写入；原任务结果不变；所有失败与回放文件保留 |
| 在线边界 | 尚未加载／实测新回执，不以预检或模拟模型当真实供应商通过；三个完整内容样例仍未过 |

私有证据：`source-url-scope-reproduction/preflight/reload/history-*`与旧投影副本。当前状态只维护股票仓库`docs/计划.md`。
