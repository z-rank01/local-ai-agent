## 实施中查出并修复的缺陷

| # | 症状 / 根因 | 修复 |
| --- | --- | --- |
| 1 | `StockPanel` 信任不含 `settings` 的响应对象，取 `.root` 抛错导致**整页白屏**；根因是 `readStockServiceResponse` 会把 SPA 兜底 HTML 解析成 `{detail: "..."}` | 改为逐级可选（`if (first && value.settings)`），并扫了同类隐患；`probe-stock.mjs` 确认兜底 HTML 路径仍会命中且不再白屏 |
| 2 | 版本切换原先按「最后一个多版本回答」定位，多回合并存时会切错 | 改为按点击的那条消息定位（`switchAssistantVersion(messageId, …)` 按该回答的 `messageId` 匹配） |
| 3 | 工作台打开时压住顶栏全部动作按钮 | 引入 `--sheet-inset`：App 把工作台宽度写到 `document.documentElement`，顶栏/阅读栏/通告条/输入胶囊让位 |
| 4 | 两级浮层原先默认展开，与「沉浸会话」的设计意图及空态文案矛盾 | 改为默认收起（`drawerOpen` / `sheetOpen` 初始 false），按需唤出 |
| 5 | 非 JSON 响应会把英文 `Unexpected token '<'…` 直接显示给用户 | `formatBackendError` 增加中文映射（非预期内容 →「后端返回了非预期内容，请确认服务是否正常运行。」） |
| 6 | 会话里两条技能简介被单行省略号截断 | 收短文案（联网搜索「联网检索并读取网页正文」、股票后台「后台任务执行与每日简报」） |
