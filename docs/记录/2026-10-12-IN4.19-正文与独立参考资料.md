| 区域 | 内容 / 行为 |
| --- | --- |
| 正文 | 判断、依据、反证、观察条件、实质缺口；公司结果存在时显示研究理由、短财务指标与比较。长分析为段落/列表 |
| 参考资料 | 来源清单、完整问题、阅读与执行概要、执行缺口、公司资料与计算、模型阶段输出；各阶段默认折叠、单列 Markdown |
| 技术备注 | 最末尾默认折叠；事件、回执等内部标识及资料编号映射。正文不展示哈希列 |
| 来源 | 资料编号可跳到参考资料对应页和条目；标题、日期、链接缺失写未记录，来源来自任务冻结简报及已保存公开快照 |
| 页码 | 正文/参考资料各自分页、记住位置；卡片标注原整篇页码，旧聊天工具契约保持原样 |
| 关闭 / 重开 | 返回报告卡、滚动定位并恢复焦点；同次页面运行恢复区域和页码，浏览器刷新后从正文首页核对 |
| 更新 / 失败 | 请求携带展示修订号；版本变化保留原页并提示重新载入；断连同样保留原页和重试目标 |
| 一致性 | 复用石墨黑阅读器、既有令牌、Markdown和Collapse；浅色主题下阅读器仍沿用原有石墨配色，无新增入口或多层卡片 |

| 原会话 report-page | 增加可选 `section=body/references`、`revision`；引用仍由同会话激活的 stock_report_read 消息取得，不接受客户端任务ID |

| 本地读取 | 股票 broker prepare→view→finish；独立于聊天活动轮次，保留F01核验，新展示正文不进入模型投影 |
| 兼容 | 未指定区域仍是原整篇；其他报告类型沿用原阅读方式。旧消息、成果和证据快照不回写 |
| 分页 | 约11000字符为展示目标，不是内容上限；按原文位置分片，续文保留围栏/表头，超长单行完整保留，不切断长表格行 |
