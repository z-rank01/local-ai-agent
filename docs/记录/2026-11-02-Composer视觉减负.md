# Composer 视觉减负实施与验收（2026-11-02）

本记录区分代码检查、真实页面结果与未覆盖项；设计口径见[前端设计摘要](../UI设计笔记.md)。

## 实施

| 面 | 改动 |
| --- | --- |
| Composer | 附件（按需）→ 输入框 → 单一状态/工具行；常态显示能力、上传和发送，运行态复用为状态及暂停/继续/停止 |
| 能力栏 | 空选择不再显示常驻说明；已选胶囊与能力入口并入底行，浮层、快捷键、会话级选择语义不变 |
| 信息与图标 | 模型选择交由顶栏；Composer 仅保留版本/文件瞬时状态；placeholder 缩短；上传使用本地回形针图标 |
| 焦点 | 发送后焦点回到输入框；状态切换只接管即将隐藏控件或已丢失的焦点 |
| 响应式 | 能力栏取消独立 40/52px 行高；触屏能力、上传、发送及运行按钮至少 44px；运行主状态省略，错误说明可换行 |

## 页面验收

| 场景 | 实际结果 |
| --- | --- |
| 常态空选择 | 通过唯一入口打开真实页面；输入框与底行两层，无“尚未挂载能力”和重复模型名，上传/发送图标可区分 |
| 已选能力 | 在新会话草稿选择公开来源 v1/v2，两枚胶囊位于底行；浮层正常打开，Esc 关闭 |
| 提交中与焦点 | 真实发送后底行切换为“正在提交…”，输入框保留且获得焦点；未再显示独立运行状态行 |
| 提交冲突 | 当前工作区已有暂停任务，后端返回执行冲突；未产生新模型调用，草稿与能力选择保留 |
| 暂停控制与触屏 | 只读打开既有暂停会话，320px 触屏视口中“已暂停 · 模型请求”与“继续/停止”共用底行；未恢复或停止旧任务 |
| 未覆盖 | 既有暂停任务形成工作区执行锁，真实 RUNNING/暂停/继续/停止操作未验收；768/1440 截图、浅色、附件、reduced-motion、3+ 胶囊及 flag off 页面未逐项核对；不以自动测试冒充这些页面结果 |
