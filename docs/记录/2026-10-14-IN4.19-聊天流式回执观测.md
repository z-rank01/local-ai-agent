# IN4.19：聊天流式回执观测

记录：2026-10-14。原比较超时请求保持未知；本批只补后续调用的本地观测，不查询、重发或补写旧调用。

| 复现 | 补修 |
| --- | --- |
| 出站参数有记录，响应终态未记录 | CompatibleClient通过同一observer在退出时记录native_model_result；响应与出站记录用本地local_attempt_id关联，该编号不发送给供应商、不替代供应商请求ID |
| 无法区分流终止与回答交付失败 | result_status与delivery_status分列；供应商已明确stop后尾部网络失败，保留已知完成，同时说明本地交付失败、用量未知 |
| 缺少诊断线索 | 仅保留格式校验后的响应ID、UUID请求ID、固定错误码、HTTP状态、结束原因及实际返回的非负整数用量；冲突或格式不识别与真正未返回分开，不保存错误原文 |

| 情形 | 记录规则 |
| --- | --- |
| stop / tool_calls | 唯一一致的终态记录COMPLETE；空内容或指定工具未返回可同时是本地交付FAILED，不认证内容质量 |
| length | TRUNCATED及原结束原因，原失败/部分输出仍保留；本批不新增截断恢复或重发 |
| HTTP 400/401/403/404/422/429 | 已知FAILED，复用既有拒绝分类；HTTP 5xx等未确认结果保持UNKNOWN |
| 网络超时、提前EOF、畸形包、流错误 | 未取得一致终态时UNKNOWN；可取得的合法响应/请求ID保留，不能自动重发 |
| 主动取消或关闭生成器 | 未取得终态仍UNKNOWN，本地交付CANCELLED；不再发出请求 |
| 响应身份或终态冲突 | CONFLICT/UNKNOWN，不静默覆盖。工具回执、原消息和旧账本不改 |
| 用量未返回 / 部分返回 | 未返回是null及NOT_REPORTED；只保存实际返回字段，不推算总数或将未知当零。非法计数不采信 |

| 范围 | 约定 |
| --- | --- |
| 请求 | 供应商地址、模型、用户思考开关、输出额度、工具选择和120秒超时均保持；不新增stream_options或其他出站参数 |
| 数据 | 复用已有audit.jsonl及回调，不新增数据库；模型正文、私有材料、密钥、错误回显和隐藏思维链不加入此记录；reasoning_tokens仅是供应商返回的计数 |
| 使用 | 观测不是供应商终态查询、重试授权或内容验收；旧98f62b请求的终态仍等待可用供应商记录，不能依据新代码推定旧调用失败或成功 |

| 验证 | 实际结果 |
| --- | --- |
| 原缺口 | 成功模拟流没有native_model_result的断言失败，保留日志；此前沙箱SSL DLL错误另存，使用原Python环境复现 |
| 受影响回归 | 50项通过：成功/工具、截断、HTTP拒绝/5xx、超时、提前EOF、身份/终态冲突、畸形包、取消、用量缺失/非法、真实Agent回调及原专业生成契约；重叠不累计 |
| 夹具修正 | 扩展测试首次把Agent第一条审计事件当native请求，1项KeyError；只按事件名称修正夹具后重测，原日志保留 |
