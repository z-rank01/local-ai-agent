# IN4.5 Qwen事件分析接口

日期：2026-10-10。当前业务进度只维护股票仓库 `docs/计划.md`。

用户调整复测为业绩/政策保留DeepSeek，事件使用Qwen3.8-Flash。聊天侧只扩展既有云端分析接口的参数传递、公开材料边界和回执；事件方法、材料、评分与业务校验仍由股票侧负责。

| 改动 | 行为 |
| --- | --- |
| 内部接口 | 原 `/api/internal/market-event-analysis` 可增加generation对象；仍需要原回环身份及股票私密令牌，不新增公开端点 |
| 显式参数 | 仅支持qwen3.8-flash的enable_thinking=true、thinking_budget、temperature、max_tokens；类型、范围和预算关系校验，拒绝额外参数及静默降级；本轮32768/0.3/65536 |
| 请求与回执 | 显式关闭联网搜索，沿用事件JSON Schema；记录发送参数、响应模型、响应ID、结束原因及用量，不返回推理正文；缺终态信息拒绝成功判定 |
| 超时 | 显式思考请求等待600秒，旧请求仍180秒；不自动重发或换模型 |
| 公开核查报告 | 仅允许static.cninfo.com.cn固定finalpage日期/数字PDF路径及public_broker_review类型；不允许认证信息、查询串或片段 |
| 失败回执 | backend_retrieval_receipt必须是固定公开字段的stock_notice_report/AKShare超时失败记录，参数仅日期与公开证券代码或全部；禁止账户信息、任意错误字符串或其它接口数据 |
| 兼容 | 无generation的旧请求继续原行为；日常模型设置与Dify发布不变，无前端、工具镜像或数据库迁移 |

通过15项定向测试与267项聊天侧全量回归（2项跳过）。首个沙箱内测试因本机_ssl DLL加载限制失败，同一环境经受审权限重跑通过；没有为通过而跳过新增测试。已通过唯一启动器重载，股票隔离身份核对且领取暂停。

首次事件回放曾因本地请求ID前缀错误被拒绝，未预留模型调用；修正后M08又被旧材料来源规则以HTTP422拒绝。两项记录留存。422在public_material校验时发生，早于供应商调用，不能算Qwen生成失败；原通用UNKNOWN分类保留并附精确的前置拒绝证据。补齐材料边界后仍使用同一公开原文，未放宽引文、方法质量或账户规则。

真实比较及其质量结论由股票仓库独立记录，不能用以上接口测试冒认通过。
