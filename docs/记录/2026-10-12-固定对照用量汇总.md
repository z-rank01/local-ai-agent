# 固定对照用量汇总

| 项目 | 实现与验证 |
| --- | --- |
| 工具 | scripts/quality_usage.py；只读现有股票model_calls表，按精确批次号汇总，输出新JSON文件，禁止覆盖历史审计 |
| 跨重启 | 从账本统计全部尝试，不依赖当前进程的calls数组；修正调用各自计数、同一call_id重复输入拒绝 |
| 未知用量 | UNKNOWN、缺失或无效用量列出call_id；已报告用量和无法确定部分分列，缺失不当作零 |
| 时间与失败率 | 已知失败/UNKNOWN占尝试数分别统计；耗时是各次已报告时长之和，不能冒充并行批次墙钟耗时 |
| 质量 | 成本信息不改变质量门槛；正式盲评仍由独立汇总工具处理 |
| 3项离线 | 多次尝试含修正及UNKNOWN、无效用量、重复及空批次通过 |
| 历史账本实测 | quality-first-fixed-v4：3次尝试（FAILED 1、UNKNOWN 2），1次有用量，已报告总token 131,956；明确usage_complete=false，未重跑旧样本或改旧评分 |
| 证据 | data/private/quality-first-20261010/comparison-v4-usage-audit-20261012.json |

使用股票虚拟环境执行：`python scripts/quality_usage.py <现有股票state.sqlite> <批次号> <新输出文件>`。工具不创建数据库、不启动服务、不发起模型请求。

当前整体状态见股票仓库docs/计划.md。
