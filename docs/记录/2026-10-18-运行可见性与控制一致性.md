# 运行可见性与控制一致性

用户确认：最后页面关闭后约15秒发起停止与整栈退出；支持步骤边界暂停及重启后人工继续；聊天、自主研究与股票专业任务一起纳入控制。当前状态只维护股票仓库 `docs/计划.md`。

## 批次1：运行与观察连接分离

| 项目 | 实现及验证 | 边界 |
| --- | --- | --- |
| 运行持有 | 后端RunManager持有任务；原聊天/重新生成/编辑接口变为创建运行并订阅，观察断开不取消；原工作区与目录重叠锁保持到执行真正结束 | 不迁移当前startup-9正在执行的生成器；代码尚未加载 |
| 唯一数据 | conversations.db增量v9保存chat_runs与轻量事件；沿原迁移生成before-v9备份，消息和task_evidence原记录不改 | 不新建数据库；大结果按消息引用回放，历史非活动版本仍可读取 |
| 接口 | GET runs、单运行、after_seq事件回读；POST control提供pause/resume/stop；原流式协议增加可选seq | 暂停边界在下一批接入真实Agent；本批仅控制器与模拟执行检查，不冒充实际暂停通过 |
| 状态 | 请求ID对应同一运行，重连不重发；明确错误后即使出现session.completed，运行仍FAILED；重启遗留运行INTERRUPTED，不自动执行 | 研究PARTIAL、供应商UNKNOWN与运行交付状态仍分开 |
| 隐私 | 新事件日志不保存reasoning；既有在线思考事件不写入新日志；工具/最终正文引用原消息，不重复复制正文 | 新增控制接口保留原本机来源与会话鉴权 |
| 离线检查 | 55项相关测试通过，1项原符号链接环境跳过；覆盖两个观察者、断线、游标、重复请求、停止前竞态、锁、鉴权、消息引用及证据隔离 | 包含现有测试，数量不与此前回归累计；无供应商/生产库调用 |
| 首轮失败 | 沙箱SSL DLL加载失败，原环境可运行；新夹具误用位置参数、可选seq=None边界、旧连接取消语义断言均已分别修正 | 原失败不当通过，不放宽权限或停止定义 |

## 批次2：步骤边界与人工续行

| 项目 | 实现与检查 | 边界 |
| --- | --- | --- |
| 暂停 | Agent在模型请求及每个工具前检查暂停；当前步骤取得终态后进入PAUSED，同进程继续保留原执行栈与工作区锁 | PAUSING期间明确仍在等当前步骤；不是强停供应商后假称可继续 |
| 安全检查点 | 在原task_evidence登记去除reasoning的公开材料索引、实际读取片段、计算/研究状态、原问题指纹、模型实际设置、提示指纹及工作区/方法 | 不新增隐藏思维链存档；未确认请求使检查点不可继续，后来的成功不清除该阻碍 |
| 重启继续 | 用户操作后新建关联运行，沿用同一研究ID及已读范围；旧终态不改。旧工具协议作为真实历史资料输入新轮次，不伪造旧原生工具调用或重发父请求 | 不是恢复原供应商连接；继续不重复自动预取，原输出/草稿和失败归档不覆盖；同一父运行并发点击只创建一个续行 |
| 恢复核对 | 检查原问题、模型/思考、方法、提示、目录和授权；证据不存在拒绝。来源JSON文件保存字节指纹，续行时通过原文件工具核对 | 旧已下载页不会补为已读；未兼容旧记录不伪造可恢复 |
| 执行停止 | ToolRouter的同步消费路径也复用原流式执行接口和进程组清理；关闭运行保留原回执/部分成果；清理错误向上传播 | 还需统一加载后的真实容器停止检查，不把受控测试算在线进程停止 |
| 离线结果 | 87项受影响循环/来源/回执组与42项恢复/研究产物/设置组分别通过，含重叠不累计；模型/工具受控，0供应商生成 | 专项包含暂停后无新增模型、同进程继续、重建服务后人工继续且原工具仅一次、并发继续、权限/证据拒绝及请求中停止不可继续 |

本批API及Agent仍未加载到startup-9；当前Qwen保持自然执行。股票逐任务控制、前端及关页退出继续下一批。批次1中“仍需真实Agent暂停/继续”是当时快照，不能代替本批离线结果或宣称整项完成。
