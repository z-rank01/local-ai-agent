# 市场简报附件配对（2026-09-26）

| 项目 | 结果 |
| --- | --- |
| 现象 | 用户询问“请帮我分析一下今天的市场”，回答称简报作为本地附件展示；读取报告的工具卡片实际没有正文 |
| 原因 | 旧网关把多个步骤的本地文本去重、拼接；聊天侧再按 Markdown 分隔符拆分。数量不一致时将全部文本误挂到最后一个有本地结果的工具卡片 |
| 修复 | 网关按步骤编号返回本地结果；聊天侧按编号配对；Web 在 Step 6 “查看报告”下直接展开正文，原始结果不重复显示报告文本；分页报告不标作完整全文 |
| 旧会话 | 从原始网关步骤恢复 4 份本地结果，简报正文重新挂到 `stock_report_read`；变更前会话库已备份到 `data/backups/` |
| 验证 | 股票网关测试 193 项通过；聊天测试 139 项通过、1 项跳过；Web 构建通过；原会话页面已核对标题与正文就地展开 |
| 边界 | 本地正文仍只存入会话附件，不回传模型；本次未评价简报内容质量 |
