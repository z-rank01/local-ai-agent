# 通用文档卡片与去重实施记录（2026-11-04）

本记录区分目标会话证据、实现、自动检查与页面未覆盖项；设计口径见[前端设计摘要](../UI设计笔记.md)。

## 原因与边界

目标会话 `aa476418cc0c4e0b`（IN4.19交付收尾 · announcement · repair3-deepseek-20261104）只有一次 `brief_publish=PUBLISHED`，成果为同一 `report.html`。结构化成果卡与助手正文独立 Markdown 链接分别触发卡片，不是重复落库。修复不修改金融发布提示、历史消息、报告文件或后端权限。

## 实施

| 面 | 改动 |
| --- | --- |
| 文档识别 | 新增 `workspaceDocument.ts`，统一安全路径键、HTML/Markdown 类型和完整文本校验；不识别 PDF、图片或任意网页 |
| 阅读分派 | 独立 HTML 进入原安全 HTML Reader，Markdown 进入原 Reader 的 Markdown 正文；沿用同一工作区预览和阅读状态 |
| 去重 | AssistantTurn 收集结构化成果的规范化路径；同回合独立链接同路径不再生成第二张卡，不按工具名或标题，跨回合及行内引用不受影响 |
| 失败兜底 | 结构化样式/预览失败仍通过通用打开函数读取原路径；两入口预览上限统一为 1,000,000 字节 |
| 视觉 | 短元信息保留胶囊，长说明改为可换行普通文字；标题安全断行，按钮不挤压 |
