## 交付规则

| 环节 | 实现 |
| --- | --- |
| 逐字引文 | 明确标为原文/原句/条款的常见中英文双引号，逐字符核对已读取ORIGINAL_TEXT/PEER_ORIGINAL_TEXT；不规范化PDF空格，不把阶段分析、检索目录或财报结构化字段当原文 |
| 压缩兼容 | 保存压缩前已授权原文的核验视图；完整的context_evidence_read分页可恢复同一来源记录，不读取其他会话或未授权证据 |
| 局部修正 | 未核验引文保留原输出，最多两次定向修正；仅开放已有查找/读取工具，不开放提交或恢复。修正后仍不成立，隔离相关段落；表格只移除对应行，其他已取得内容保留 |
| 流式与取消 | 普通解释继续流式展示；可能的原文引述先核验再发表，思考展示沿原设置。取消或供应商失败保留部分输出；供应商UNKNOWN不因此重发 |
| 历史与界面 | 未通过稿保存在现有protocol元数据，后续模型视图收到修正说明；不把错误稿写成已确认事实。原消息、报告及阅读器保持，未新增UI入口或样式 |
| 只生成回答 | 仍核对已有材料；没有工具授权时只局部隔离不成立引述，不额外调用模型、来源或后台 |
| 观测 | 原audit.jsonl记录每轮实际提供的工具名称及引述核验结果；不记录请求正文、密钥或隐藏思维链 |
