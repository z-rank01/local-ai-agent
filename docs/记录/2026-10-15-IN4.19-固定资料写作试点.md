## 有限执行门槛

| 顺序 | 验证及停止条件 |
| --- | --- |
| 1 新预算确认 | 原六次自动验收预算已结束，本次不续用。提议新写作试点1次，明确完成且有具体可修缺陷时最多1次复验；待用户确认，不把继续工作解释为恢复旧循环 |
| 2 正式生成 | 唯一9510入口、新普通写作会话、原工作区与授权。只处理给定公开材料，不启动研究或交易；如采用无工具写作，只限定本次能力隔离，不改变项目默认能力 |
| 3 审查 | 按独立review-checklist人工逐项核对确定程度、期间/单位、条件推理、事实引用与研究判断；结构合法不认证语义，同模型自评不作为合格依据 |
| 4 排版/交付 | 保留原模型稿及实际参数/用量/终态；只对合格稿做确定性排版、图表及显示属性标注，再经原HTML卡片交付。失败不手改成模型成功 |
| 5 停止 | UNKNOWN立即隔离，不换ID重试；再次完成但内容失败则记录能力或策略缺口，停止追加提示/框架；另两例待首例结果再决定，不自动扩成三例循环 |
| 实际用量 | 按供应商请求计数，若出现额外摘要/工具阶段要单独记录，不能称一个用户回合仅一次模型调用；未知用量不填零 |
