# 能力管理交互与编辑器（2026-10-28—29）

本记录为本批实现与验证证据，不维护第二份进度。当前状态见股票仓库 docs/计划.md。代码批次：7138074（接口）、86180e9（统一列表）、b37c833（文件提交与冷启动修复）、c4f1cf8（草稿、作用范围与布局）、6015d63（内置包源位置）。

| 交付面 | 实现与边界 |
| --- | --- |
| 统一能力列表 | 搜索、类型筛选、数量、来源及作用范围；搜索／金融设置归入插件详情，同一类型＋ID 一张卡片；不合并不同 ID 方法包 |
| 操作与版本 | 统一开关、导入、差异、激活、回退、移除／卸载；已安装状态与失败候选分开；内置包禁用不支持的卸载 |
| Skill 编辑 | 只编辑源目录现有 UTF-8 文本 ≤256 KiB；Runner 校验候选包，原 FileService CAS 原子提交，回读并捕获版本；不执行脚本、不新建文件、不编辑插件代码 |
| 草稿与作用范围 | 离开前保存／放弃／继续；失败保留草稿；工作区切换清理 Skill 数据，保留 Plugin 真实状态；忽略过时响应 |
| 动效 | 原 Collapse、Popover、确认框及令牌；隐藏内容 inert；少量透明度／网格过渡；系统减少动效时取消相应动画 |

## 实际发现并修复

| 问题 | 修复与验证 |
| --- | --- |
| Runner 对文件服务创建目录无原子替换权限 | 初次保存明确失败且保留草稿；改为 Runner 只校验、原 FileService 提交，没有修改目录权限或添加宿主写入后端；重建后页面保存成功 |
| 冷 Build 在完整退出后未恢复默认工具组 | 原脚本仅重建“已有”容器，完整退出后默认组不存在；同一启动器 Build 分支恢复默认组，命名工作区仍按需；冷启动后 5 个 Plugin 全部 ACTIVE |
| 内容与哈希可能来自不同读取 | 源文件读取改为同一次有上限的字节读取产生正文与 SHA256 |
| 草稿离开及窄卡片布局 | 复用全局三选确认、跨工作区隔离与双行摘要布局；真实页面确认保留草稿、保存离开及390px无横向溢出 |
