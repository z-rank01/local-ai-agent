## 方法与判断

| 发现 | 处置 / 限制 |
| --- | --- |
| 直接原文+字段到正文仍编造推断 | 首稿完整保留，人工逐项反馈，不手改为模型合格 |
| 沿失败稿修订会沿用错误 | 提供事实/期间/出处配套卡；新会话排除旧答，仍有错误。不能把历史污染当唯一因果 |
| 简化输入不等于内容正确 | 第四次输入14192字符，仍多处错误；无需继续增加观测字段、语义认证框架或强化拦截 |
| 需要下一项选择 | 建议独立写作模型对照，保留同一事实卡与人工核对规则；尚未更换任何模型。当前停点是方案需用户决定，不是调用次数上限 |
| 失败不否定人工成果 | 人工三份简报及用户阅读验收继续有效；自动资料到正文、自动HTML交付尚未完成，IN4.19整体PARTIAL |
