# 搜索批次游标

| 项目 | 实现与证据 |
| --- | --- |
| 原限制 | web_search固定pageno=1，单页直接切前max_results；剩余结果不可读，摘要超过300字直接截断 |
| 新请求 | page、offset、page_hash；max_results保留单批最多20项，不再代表总可读量 |
| 新回执 | next_cursor、page_result_count、page_hash、coverage；每批返回完整摘要 |
| 页变化 | 页内续读要求指纹匹配；变化明确拒绝并要求重新读取本页、按URL去重，不静默跳过 |
| 失败与空页 | 引擎失败为PARTIAL/UNAVAILABLE；PAGE_EMPTY只表示本页空，不证明全网无证据；保留原始错误区分 |
| 离线证据 | 4项专项全部通过，含60条跨页无遗漏及真实HTTP处理函数；另45项聊天回归中44通过、1因宿主缺少bs4跳过，已由现有股票虚拟环境补验该处理函数 |
| 模拟范围 | 搜索提供方响应为夹具；未调用真实SearXNG，不代表提供方分页能力已验 |
| BFF接线 | stock-public-search可选cursor保留page/offset/page_hash及next_cursor；旧请求保持兼容；新请求要求工具返回真实分页元数据，不支持或回退游标明确拒绝 |
| BFF状态 | PARTIAL和UNAVAILABLE保留；PAGE_EMPTY仅为空页；URL全部被安全过滤时仍保留下一批游标；页变化返回同页从头读取游标 |
| BFF验收 | market_research与search_paging共24项：23通过、1宿主缺bs4跳过（此前已在股票虚拟环境补验）；本次新增3项接口场景，覆盖旧工具拒绝、异常游标、部分失败、空页、页变化 |
| 当前缺口 | 股票任务检查点及自动续查尚未接入游标；查询限制、去重停止与后台续行还需联调；BFF变更尚未重启上线 |
| 部署门禁 | skills代码须通过唯一入口start-daily.ps1 -Build重建，随后核对容器OpenAPI含page/offset/page_hash并做真实分页；本轮未重建，不标在线通过 |
