# 搜索批次游标

| 项目 | 实现与证据 |
| --- | --- |
| 原限制 | web_search固定pageno=1，单页直接切前max_results；剩余结果不可读，摘要超过300字直接截断 |
| 新请求 | page、offset、page_hash；max_results保留单批最多20项，不再代表总可读量 |
| 新回执 | next_cursor、page_result_count、page_hash、coverage；每批返回完整摘要 |
| 页变化 | 页内续读要求指纹匹配；变化明确拒绝并要求重新读取本页、按URL去重，不静默跳过 |
| 失败与空页 | 引擎失败为PARTIAL/UNAVAILABLE；PAGE_EMPTY只表示本页空，不证明全网无证据；保留原始错误区分 |
| 离线证据 | 4项专项全部通过，含60条跨页无遗漏及真实HTTP处理函数；另45项聊天回归中44通过、1因宿主缺少bs4跳过，已由现有股票虚拟环境补验该处理函数 |
| 模拟范围 | 搜索提供方响应为夹具；未调用真实SearXNG，不代表提供方分页能力已验 |
