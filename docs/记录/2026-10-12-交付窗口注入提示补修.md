## 搜索起步的自动交接补修

| 项目 | 实现与验证 |
| --- | --- |
| 时间边界 | 股票工具可用且质量优先启用时，首次公开搜索/抓取也启动交付计时；不再必须先调用stock工具才有边界 |
| 无引用准备 | 交接允许先通过既有stock_market_brief_find/stock_research_find取得会话引用，随后只开放只读提交；不刷新简报，不另起服务或数据库 |
| 授权与结果 | 提示限定用户已授权的公开股票/公司/产业问题；非股票研究不能改写成股票任务；允许模型说明缺口而不提交，只有TASK_SUBMITTED能作为已受理依据 |
| 拒绝说明 | 当前交接未开放搜索时不再谎称联网配额用尽，也不要求用户重复发送继续 |
| 验收 | 51项质量循环与股票桥接回归通过，含新增搜索→引用→受理→交付、无法交接时如实收尾；重入、UNKNOWN和redo限制沿用原检查 |
| 环境 | 两次受限进程回归遇Conda SSL DLL加载错误；正常本机环境带Library/bin运行后51项全通过，不将环境错误掩饰为代码已通过 |
| 剩余 | 当前BFF未重载；自然十分钟、真实检索/受理及同任务续行仍需唯一入口在线验收；通用非股票后台研究未实现 |
