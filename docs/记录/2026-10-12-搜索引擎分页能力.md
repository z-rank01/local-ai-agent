# 搜索引擎分页能力

| 项目 | 实现与证据 |
| --- | --- |
| 在线问题 | v9公开补查及两个独立公开查询返回无关结果；360search解析错误、quark验证码。相关性问题仍未解决，不能用扩大批次数替代来源质量 |
| 实际能力 | 运行中SearXNG的`/config`：Bing分页与时间筛选均为false；360search、quark分页为true。已安装Bing源码同样明确不支持分页 |
| 新回执 | 工具启动时读取已启用通用引擎的分页能力；结果附`pagination_support`和`non_paging_engines`，BFF保留类型化诊断；不改变引擎启用设置 |
| 覆盖语义 | 全部引擎明确不支持翻页时仍可完整读完当前页，不伪造下一页游标；混合能力保留后续页机会；能力查询失败标UNKNOWN，不冒充完整检索 |
| 快照 | 能力随原始结果页一起冻结；页内续读不重新取结果或改写覆盖说明；诊断不是金融事实 |
| 专项验收 | 30项通过，含真实HTTP处理函数、启动读取能力、25条首批跨批读取、混合能力、能力接口失败、BFF类型投影；未调用真实模型 |
| 完整回归 | 宿主unittest共318项，314通过、4跳过；新增HTTP处理函数测试因宿主缺bs4跳过，但已在股票虚拟环境的30项专项中实际通过 |
| 部署 | v9终止后，经唯一入口startup33 -Build重建；startup34沿用同一镜像及独立验收状态，搜狗设置已加载 |
| 仍需完成 | 公司关联与完整开放研究质量仍待验；分页技术通过不等于取得一手事实 |
| 备选源实测 | 搜狗当前两个公司查询相关；同一吉峰年报查询两页共20个不同URL，首/次页6/8个HTTPS，无引擎错误。已恢复配置，待唯一入口加载后验证真实研究；DuckDuckGo遇验证码，Google中英文均空，不启用 |

原始公开探测在`data/private/quality-first-20261010/search-relevance-v1/`；当前整体进度仅维护于股票仓库`docs/计划.md`。
