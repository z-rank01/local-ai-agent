# IN4.21 跨日跟踪 Web 工具桥接

| 工具 | 作用 | 引用来源 |
| --- | --- | --- |
| `stock_track_follow` | 明确关注已完成研究中的主题或已核验公司 | `stock_theme_research_find` 的任务引用 |
| `stock_track_find` | 查找关注/忽略状态与最新变化 | 当前股票状态库，返回会话安全引用 |
| `stock_track_read` | 按页读取旧观点、新事实、反证、来源与缺口 | `stock_track_find` 的跟踪引用 |
| `stock_track_ignore` | 停止后续跟踪，历史保留 | `stock_track_find` 的跟踪引用 |
| `stock_track_review_find` | 查找日程生成的复查报告 | 返回任务引用，交给 `stock_report_read` |

| 边界 | 实施 |
| --- | --- |
| 用户意图 | 关注/忽略须在当前原话中明确提到对象；模型不能凭旧上下文自行改状态 |
| 会话与账户 | 任务、跟踪引用分别校验，不接受其他会话令牌；不另建库或启动入口 |
| 云端可见性 | 仅公开论点、事件引文、来源与缺口；股票仓库字段白名单剔除账户与完整 F01 |
| 运行验证 | 聊天侧 154 项（1 跳过）与 Web 构建通过；唯一入口 Web 会话已完成关注、读取、忽略和历史再次查找；新日期观点变化仍待证据 |
