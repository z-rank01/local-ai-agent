# 固定证据策略接线

| 项目 | 实现与边界 |
| --- | --- |
| 模块 | scripts/quality_replay_policy.py；仅策略选择与输出校验，不含网络请求、密钥或调用预留 |
| 原策略 | 同一输出契约严格校验；格式修正耗尽后整份拒绝，C01/C02沿用单请求处理 |
| 新策略 | 复用股票生产实现的C01/C02分层阅读及C01/C02/C03逐项隔离；局部保留必须在最后一次格式修正后，不能提前当完整结果 |
| 确定性检查 | 连接真实股票契约及编排：错引用局部隔离、有效输出一致、UNKNOWN不改判成功；新策略实际分窗并复用未知节点，C03复用已完成窗口；材料或分组变更拒绝。6项通过，无模型调用 |
| 运行方式 | 设置STOCK_REPLAY_TEST_ROOT为已连接股票仓库，再运行tests.test_quality_replay_policy；未提供仓库时明确跳过 |
| 执行接线 | execute_fixed_case调用生产ThemeReadingRunner/run_company；冻结输入哈希、执行版本及分组绑定检查点。候选回放驱动data/tmp/run_quality_comparison_v5.py已接入该编排和validate_result，并检查策略/驱动哈希；仅语法检查，未执行 |
| 未完成 | 候选驱动已补八项定向故障恢复检查，完整批次预检/排程仍未验；材料、UNKNOWN依赖隔离、盲评分组和新批次还未冻结，不能声称36份对照已开始或有质量增益 |
| 历史隔离 | 原始回执复核确认Q01两笔、Q05/Q06各一笔UNKNOWN；无响应ID或可关联的现有研究账本终态，全部保留隔离。另一独立公告仅为候选；不能仅换ID或批次重跑原未知问题 |

整体进度仅见股票仓库docs/计划.md。

## 驱动故障恢复

| 检查 | 结果 |
| --- | --- |
| 回执已保存、节点文件未保存 | 明确截断保持拆分标记，已知供应商拒绝保持FAILED；修复旧恢复分支误判UNKNOWN |
| 传输解码异常 | invoke返回前的ValueError保持UNKNOWN，不按模型格式错误重发；修复旧异常分类过宽 |
| 原调用未知 | RUNNING/UNKNOWN均不重发；C03已知截断可恢复扩额，但扩额调用UNKNOWN仍隔离 |
| 其他重入 | 成功结果复用；三份已知格式失败恢复为失败，不发第四次 |
| 检查方式 | tests.test_quality_replay_driver读取候选驱动的真实ReplayRunner类AST，注入离线账本和传输；不执行顶层凭据读取或联网预检。8项通过，不代表完整驱动在线验收 |
| 运行 | 设置QUALITY_REPLAY_DRIVER为候选脚本路径，STOCK_REPLAY_TEST_ROOT为股票仓库，再运行上述测试；缺依赖时明确跳过 |
