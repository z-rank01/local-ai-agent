## 接口与数据

| 接口/字段 | 语义 |
| --- | --- |
| GET/POST /api/workspaces | 列表及创建命名工作区；目录根包含稳定 ID、本机路径和显示名称 |
| PATCH/DELETE /api/workspaces/{id} | 修改配置或删除未被会话引用的工作区；不删除原文件；容器清理失败保留关联 |
| POST /api/workspaces/{id}/activate | 明确应用待生效配置，验证两个工具服务的工作区 ID 和版本 |
| 会话 workspace_id / workspace_name | 创建和首次发送绑定；已有会话不能换归属；列表可按工作区查询 |
| search_snippet | 正文搜索命中证据；界面搜索可跨工作区 |
| /api/workspace/*?workspace_id=… | 所有文件操作携带工作区身份；原 /workspace 路径兼容默认工作区 |
| POST /api/workspace/directory、/rename | 结构化目录创建和文件重命名；不允许覆盖或重命名根目录 |
| tool_catalog | 工具中文名和分组；保留 tools 字段兼容已有客户端 |
| 409 detail.conversation_id | 指明当前执行会话，冲突请求不入队、不存用户消息 |

外部根目录不会复制进托管目录；移除后重新添加恢复同一根 ID。主要目录可以是外部根或托管 /workspace。新的工作区云端读取/写入默认关闭，授权扩展需要确认；默认工作区保留旧路径授权兼容。工作区配置使用现有库的增量迁移，不迁移或复制用户文件、会话库和模型账本。
