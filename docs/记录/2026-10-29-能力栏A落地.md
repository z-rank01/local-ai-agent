# 能力栏 A 落地与验证（2026-10-29）

本记录是本批实现与验证证据；设计契约见[能力栏 A 规范](../capability-bar-a-final.md)，定稿原型见[能力栏 A 原型](../原型/capability-bar-review.html)。当前状态仍以股票仓库 `docs/计划.md` 为准。

## 交付面

| 面 | 实现 |
| --- | --- |
| 能力带 | `apps/web/src/app/CapabilityBar.tsx`：Composer 内固定 40px 单行；左侧已选胶囊（最多 2 项 + `+N`），右侧唯一「能力」触发器 |
| 浮层 | `apps/web/src/app/CapabilityPopover.tsx`：374px dialogs、搜索、全部/技能/插件筛选、添加/移除、加载/空/无结果/错误/不可用状态 |
| 数据适配 | `apps/web/src/panels/capabilities/capabilityModel.ts`：真实 Plugin/Skill 映射、状态、显示名/图标、前 2 项、搜索、最近使用、去重 |
| 注册表 | `apps/web/src/lib/capabilityRegistry.tsx` + `App.tsx`：工作台与能力栏共享一个 `useInventory`，避免重复 Skill freeze；Plugin 先到先显示，Skill 后到 |
| 会话状态 | `conversations.db` v11 `capability_ids`；`skill:<name>` / `plugin:<id>`；PATCH、创建、chat、edit、regenerate 在受理时写入 |
| 运行消费 | `harness/capabilities/selection.py`：非空选择只收窄本轮 `SkillSession` 的 `versions` 与 `capabilities`；空选择不缩窄；不改工具 schema、权限或插件生命周期 |
| 可访问性 | 已选区 `role=group`；触发器 `aria-haspopup/expanded/controls`；浮层 `role=dialog aria-modal=false`；筛选 tab 的 `aria-selected/aria-controls`；行 `aria-pressed`；焦点循环、Esc 回焦、移除胶囊后焦点下一项 |
| 回滚 | `VITE_CAPABILITY_BAR_A=off` 构建；旧 Composer、不发送 `capability_ids`、不写选择；数据库列与已有值保留 |
| 文档 | 规范/原型归档；`UI设计笔记`、`AGENTS.md`、部署/日常/回归指南、`harness/README.md` 同步；本记录 |

## 实现边界

| 项目 | 本批选择 |
| --- | --- |
| 空选择 | 沿用全部已启用能力，保持现有会话与运行行为不回归 |
| 选择影响 | 只影响本轮 Skill/Plugin 发现目录；不硬性摘除工具 schema、不改权限、不启停插件 |
| 选择粒度 | 会话级；不是工作区全局偏好 |
| 最近使用 | 本地 localStorage，最多 3 个；不做账号同步 |
| 搜索 | 本地过滤；当前注册表 18 项，不做远端搜索/防抖 |
| 管理 | 浮层「管理能力」跳到工作台能力面板；安装/版本/权限不进入 Composer |
| 动效 | 打开复用共享 `.pop` 的 150ms 入场；关闭沿用共享 Popover 的立即卸载（P1 偏差） |
| 埋点 | 本仓库没有遥测管线；不伪造事件，P1 埋点不适用 |

## 实际发现并修复

| 问题 | 修复与验证 |
| --- | --- |
| 工作台与能力栏各建一个 `useInventory`，并发触发 Skill freeze，能力栏只显示 Plugin 或长时间空载 | 改为 App 级共享 `CapabilityRegistry`；Plugin/package 到达即发布，Skill 随后补齐；页面实测 18 行（5 Plugin + 13 Skill） |
| 浮层锚定在触发器上，在 320px 会盖住 Composer 顶部约 7px | `Popover` 增加 `placementAnchor` + `upOffset`；能力栏以 bar 根定位；320×568 实测浮层 bottom 421、composer top 427（6px 间隙） |
| 迁移测试仍按 `.before-v10` 断言，且模拟 v9 库缺少 `DROP COLUMN`，v11 会因重复列失败 | 测试先 `DROP COLUMN capability_ids`，备份断言改为 `.before-v11.sqlite`；迁移、原会话保留通过 |
| 能力卡片引用未定义的 `--text-md` | 改为 `--text-sm` |
| 搜索框同时出现外层容器与 `input` 两圈焦点环，且 4px 偏粗 | 外层 `.capbar-pop-search:focus-within` 唯一负责；`input:focus/:focus-visible` 清掉全局 `box-shadow` 与圆角；容器改用 2px `--focus-ring-sm`；截图复核为单环 |
| 挂载后 toast 先偏右再横向跳回中间 | `rise` 动画的 `transform` 覆盖了 toast 静态 `translateX(-50%)`；新增 `centered-rise`（`translate(-50%, 8px)` → `translate(-50%, 0)`），toast 与 notice-bar 共用；CDP 采样 28 帧 center 恒为 720、range 0 |
| 320px 下触发器文字与两枚胶囊争宽，名称只剩首字 | ≤380 胶囊限宽；≤340 触发器图标化；320 实测无横向滚动（scrollWidth 320） |

## 未覆盖 / 后续

- 硬性工具/权限门控、项目级默认能力、拖拽排序、批量操作、远端搜索与账号级最近使用不在本批。
- P1 的关闭动画与埋点未实现；关闭沿用共享浮层行为，埋点无管线，不记作通过。
- 会话选择的真实页面 PATCH 未在用户现有会话上执行（避免改写用户数据）；持久化由 store/API 测试覆盖，截图中的 6 项选择是新任务 draft，不落库。
- 当前 BFF 在最后一批 `service.py` 顺序调整前启动；下一次唯一入口重启后生效。功能核心（v11、选择读写、发现过滤）已由测试覆盖。
- OS 减少动效偏好与真实读屏未在本批浏览器启动；全局 1ms 规则与新增动画使用令牌已静态核对，键盘/焦点用 CDP 实测。
