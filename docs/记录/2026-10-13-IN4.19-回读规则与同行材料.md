## 已授权的公开正文解释

| 项目 | 约定 / 实测 |
| --- | --- |
| 用户授权 | 自动审批两次以新增持续外发路径为由拒绝；用户随后明确回复“允许，接入云端解释”。授权仅已授权报告读取及原云端开关开启时，把与阅读器一致的公开研究正文交给当前配置Qwen聊天模型；账户、持仓、密钥和技术附录不加入 |
| 适用报告 | 主题成功窗口部分综合，以及question_delivery_version=1的公司/公告问题报告；日常与账户视图排除 |
| 旧契约 | 原body、整篇page_count及本地附件保持，兼容旧页引用；增加answer_pages供解释，页数仅对应新版正文 |
| 内容与采信 | 只使用已保存的可核验阶段、财务与公开证据；阶段输出不是独立来源，后续补查未完成不能变为最终综合 |
| 云端字段 | 每个正文分片复用原local_report_page白名单；超过单字段容量时完整分片，不丢尾部反证。权限政策文件、云端目的地及用户开关不变 |
| 聊天提示 | 优先解释新版正文，区分执行与研究状态；不模拟报告卡、哈希或执行状态表，链接实际写出，名称/期间/单位保留，日期和风险强度须有依据 |
| 待上线 | 本批源码已实现；唯一入口加载、实际新正文进入聊天输入、针对新问题的解释及原文回读尚待实测，不重复原失败问题 |
