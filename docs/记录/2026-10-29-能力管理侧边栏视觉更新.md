# 能力管理侧边栏 v2 视觉与交互落地（2026-10-29）

本记录是本批实现与验证证据；设计输入为[能力管理原型](../原型/capability-manager.html)，交付拆分参考[能力管理落地计划](../capability-manager-rollout-plan.md)，Composer 选择语义仍以[能力栏 A 规范](../capability-bar-a-final.md)为准。当前进度只维护股票仓库 `docs/计划.md`。

## 范围

本批只做右侧 Sheet 的「能力」面板：

- 视觉层级：hero、搜索、全部/技能/插件筛选与计数、启用汇总、单张能力组、行内开关/上下文/状态、页脚统计以及历史入口。
- 交互：搜索、筛选、行展开、开关、停用已选能力后的会话移除与撤销、导入/刷新、加载/空/无结果/错误/无效 Skill 状态。
- 保留原有深度能力：概览、设置、文件、版本、导入、检查更新、卸载/移出、Plugin/Skill 状态与错误。
- 不做 rollout plan 的运行时灰度、双读双写/新 store、遥测、市场/推荐、拖拽、批量导入、硬工具门控或无数据迁移。

## 实现

| 面 | 改动 |
| --- | --- |
| 选择接线 | `App.tsx` 抽出 `setCapabilitySelected`，Composer 与侧栏共用同一 selection ref；`Sheet.skills` 增加 `selectedCapabilityIds` / `onCapabilitySelected` |
| 数据适配 | 新增 `panels/capabilities/capabilityManagerModel.ts`：display name/icon、source/origin、enabled/selected、状态 tone、搜索/筛选/历史计数；真实数据来自共享 `useCapabilityRegistry` |
| 新 manager | 新增 `CapabilityManager.tsx`：hero、搜索、筛选、分组列表、页脚、空/骨架/错误；`SkillsPanel.tsx` 变成构建 flag 选择器 |
| 旧界面 | 当前 manager 原样移至 `SkillsPanelLegacy.tsx`；`CapabilityEntry` 默认 `legacy` 外观不变，新路径传 `variant="v2"` |
| 行 | v2 行包含 32px 图标、display name、`对话中`/状态 badge、2 行描述、类型/source/origin、40×24 Switch、更多菜单、展开 chevron；详情 tabs 全部保留 |
| 跨面同步 | 停用已选能力成功并刷新后调用 `onCapabilitySelected(false)`；Toast「撤销」重新启用并恢复选择；App 切换 conversation/workspace 时清除带 action 的旧 Toast |
| Toast | `notify` 增加可选 action（4s），`Toast` 渲染 action 按钮；沿用 `centered-rise`，水平中心不跳 |
| Flag | 复用 `VITE_CAPABILITY_BAR_A` 作为能力面总开关；代码别名 `CAPABILITY_MANAGER_V2`；关闭时旧 Composer + 旧侧栏 |
| 样式 | `.capm-*` 与 `.cap-entry-v2` 新作用域，旧 `.cap-*` 不动；颜色/字号/圆角/动效只用令牌；`.capm` 容器查询处理窄 Sheet |

`flags.ts` 的注释同步说明：该变量现在同时回退两个面。

## 视觉适配

原型是 720px 独立深色 drawer；宿主已有 400px（可拖到 760）Sheet 和 Panel 折叠头，因此：

- 原型的独立 topbar/close/reopen 不复制；Sheet head + Panel「能力」承担。
- Hero 使用 `--text-lg`（21px），不是原型的 26px；行标题 `--text-sm`，描述/meta `--text-xs`；原型的 10.5/9.5px 不直接落地。
- Switch 复用全局 40×24（原型 37×21）；粗指针外层 44px 命中。
- 颜色/边框/圆角/焦点/动效全部来自现有令牌；不固定深色，深浅主题都测。
- 无效 Skill 保留独立错误块；历史入口移到页脚，避免增加第四种类型筛选。
- Toast 是全应用统一浮层，不是侧栏专用 toast；撤销按钮在全局底部，仍可操作。

## 未覆盖 / 限制

- 停用/撤销用拦截的测试 API 验证，未在真实用户 Skill/Plugin 上做破坏性 toggle；后端既有能力生命周期测试仍是服务端事实来源。
- 真实数据没有已移除历史行，history 开关的实际行渲染未在页面覆盖；`managerCounts`/过滤对 removed 的纯函数测试已覆盖。
- 未启动真实屏幕阅读器、OS 减少动效偏好和 200% 浏览器缩放；用 320/768 等效宽度与 CDP 键盘/焦点核对替代。reduce 规则沿用全局 1ms。
- Sheet 760 最宽未单独截图；布局采用容器查询，默认 400 与 320 全宽已验。
- 未接入 rollout plan 的遥测事件；本仓库无遥测管线，不伪造。
- 全局 Toast 的位置与 Composer 有既有重叠，不是本批新增；本批只加 action 与居中稳定性。
