# 研究验收与回合状态补修

当前批次状态统一见股票仓库 `docs/计划.md`。

| 项目 | 实测与修改 | 边界 |
| --- | --- | --- |
| 页面提交 | 唯一入口隔离状态，新会话提交农业机械反证问题；完整问题已进入股票任务 | 不恢复旧 UNKNOWN，不刷新源简报 |
| 整轮误标失败 | 一次报告读取参数失败、修正成功、研究正常受理后，页面仍把助手整轮标为失败；改为最终回答状态与工具步骤状态分开判断 | 工具失败仍在轨迹显示；回答中断、未完成失败步骤及正在执行状态保留；不把正常回答等同研究完成 |
| 回归 | 三项状态测试通过，前端类型检查及构建通过；刷新真实历史会话后整轮不再误标失败，原失败节点仍可见 | 构建使用项目内专属临时目录，避免 Windows 系统临时文件占用 |
| 股票暂停 | 真实暂停后仍出现第二次 C01 请求，定位到专业运行器未绑定暂停信号；股票侧修复并增加真实 API 组合回归 | 详细任务回执、研究质量及在线复验记录在股票仓库 |
| 原始证据 | `data/private/quality-first-20261010/open-counterevidence/`；`recovered-turn.png` 保存修复后页面 | 原始结果不纳入 Git |
