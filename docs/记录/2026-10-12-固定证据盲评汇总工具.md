# 固定证据盲评汇总工具

| 项目 | 实现及边界 |
| --- | --- |
| 工具 | scripts/quality_review.py；仅处理已保存验收文件，不调用模型、不打分、不启动服务或改账户 |
| 隐藏分组 | pack只向reviewer目录交付匿名编号、同一证据材料和显式分析；组别、调用回执及执行元数据保留在评审目录之外；原结果不改写 |
| 完整性 | 六场景×两策略×三份，36个唯一位置；缺结果、UNKNOWN、失败、缺评审均保留并判INCOMPLETE，不删除缺陷或用换ID补齐 |
| 绑定 | 冻结评分规则、材料、原结果及评审包哈希；重复/未知样本、改写结果或评分来源错配拒绝汇总 |
| 原门槛 | 六维各0—2，逐场景均值不下降，至少四场景目标维度增益，四类零容忍事件为零；不按长度、调用量或成本加分 |
| 人工边界 | 每份评审必须显式声明是否边界样本；边界样本需要具名人工复核后才能参与通过判定，不自动代填 |
| 9项离线检查 | 完整门槛、缺失/未知/失败、零容忍、四场景增益与单场景退步、人工复核、篡改/重复、非法分数、弱化门槛、文件打包/汇总及禁止覆盖通过；使用合成分数，只验证门禁算法 |
| 未完成 | 正式新批次材料未齐、36份有效输出及盲评未开展；本工具通过不代表模型质量通过，开放研究和唯一入口E2E仍独立验收 |

## 离线验收文件命令

| 步骤 | 命令 |
| --- | --- |
| 打包 | `.conda/python.exe scripts/quality_review.py pack <批次目录> <新评审包目录>` |
| 汇总 | `.conda/python.exe scripts/quality_review.py summarize <批次目录> <新汇总目录> --pack <评审包目录> --reviews <已评分JSON目录>` |

评分JSON含blind_id、packet_hash、rubric_hash、六维scores、四类hazards布尔值、rationale、reviewer、boundary；边界样本另含human_review.confirmed及reviewer。评分依据采用生成前冻结的rubric，不由工具编造。

当前状态统一在股票仓库docs/计划.md。
