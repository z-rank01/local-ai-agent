### 深色计算样式审计

读取实际 DOM 文字与必要图标的颜色、祖先背景、透明度，按普通文字 4.5:1、大字/图标 3:1 检查；禁用控件不计入。色彩计算支持浏览器序列化的 rgb/rgba/Oklab，转换参考 [W3C CSS Color 4](https://www.w3.org/TR/css-color-4/#color-conversion-code)。该脚本是状态采样工具，不替代完整无障碍审计或图片/渐变视觉检查。

| 状态 | 已采样最低比值 | 结果 |
| --- | --- | --- |
| 普通会话首屏 | 4.85:1 | 无失败 |
| 设置外观 | 6.20:1 | 无失败 |
| 工作台/技能 | 4.85:1 | 无失败 |
| 报告阅读 | 5.93:1 | 无失败 |
| 含代码会话 | 4.85:1 | 无失败 |
| 含代码阅读器 | 5.64:1 | 无失败 |
| 模型弹层正常/选中 | 4.85:1 | 无失败；选中标题与小标签原先约 4.19–4.39:1，已用更亮文字阶梯修复 |

代码标题原先在最深代码条上约 3.95:1，已通过专用语义令牌修复。浅色既有不足单独保留，不在本轮改配色；固定首屏像素一致确认未新增该屏退化。
