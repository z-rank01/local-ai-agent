## 聊天侧接入约束

| 项目 | 处理 |
| --- | --- |
| 标准技能加载 | 复用 `skills/runner/skill_md.py` 与 `skill_registry.py`；SKILL.md 可发现不等于其中脚本可直接运行 |
| 方法选择 | 复用会话选择与股票任务的入队冻结；金融方法正文和版本由股票仓库负责，聊天侧不再维护一份 catalog |
| 数据与隐私 | 股票取数仍走股票后台的数据网关；完整账户及私有材料不因新方法进入云端历史 |
| 脚本环境 | runner 镜像 Python 3.11 与股票 Python 3.13 不能混为同一环境；Kimi 四个新语法脚本无法直接在 3.11 解析 |
| 展示 | 复用研究查找、逐页读取、已授权公开证据和本地附件；报告样式不改变研究状态 |
| 开关与生命周期 | 仍在现有股票技能之内增加方法，沿用唯一启动器与既有控制；不新增金融入口或后台 |
| 首批时点 | IN4.20 的真实研究质量验收收口后再改方法；本轮只提交文档与离线评估工具 |

排序是适配顺序。真实模型效果、真实数据接口与收益尚未比较；后续必须按照主方案的同证据对照和唯一入口验收完成后，才把某项标为业务可用。
