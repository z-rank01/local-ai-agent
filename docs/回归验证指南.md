# 回归验证指南

本页给出每次改动应选择的验证范围。旧 44 案例矩阵、长对话脚本与详细证据格式保存在[原稿](./记录/回归验证指南-原稿.md)；当前任务状态见股票仓库 docs/计划.md。

## 按改动选测试

| 改动 | 最小检查 | 关键观察 |
| --- | --- | --- |
| BFF、会话、模型路由 | 对应单元测试 + Web 对话 | 实际模型、流式事件、刷新和历史一致 |
| 会话方法字段 | 新旧会话库迁移 + 切换会话/重启 + 提交新任务 | 单选只影响本会话后续任务；入队版本冻结，旧任务不变 |
| 工具/技能 | 工具注册测试 + 一次真实调用 | 可见目录、执行结果与错误一致，不虚构成功 |
| 文件/代码执行 | 隔离文件案例 + 回读 | 编辑差异、退出码、输出和进程收尾 |
| 股票桥接 | 双仓库契约测试 + 隔离状态目录 | 身份、引用、受理/完成区分、附件本地直出 |
| 恢复/启停 | 服务生命周期测试 + 页面操作 | 暂停、重开、补跑、人工确认和退出顺序 |
| 前端 | npm run build --prefix apps/web + 目标页面检查 | 状态、按钮和结果卡片与服务一致 |
| 文档 | 链接、表格和路径检查 | 当前入口不被旧快照覆盖 |

## 必测场景

| 组 | 操作 | 通过标准 |
| --- | --- | --- |
| A 模型与对话 | 切换模型、刷新、编辑重发、重生成 | 请求走选中模型；旧回复来源不变 |
| B 文件与计算 | 读文件、运行 Python、错误后修正 | 模型引用真实输出，错误可复查 |
| C 编辑与命令 | 局部替换、冲突、搜索、测试、停止 | 差异可见；退出码和子进程状态真实 |
| D 技能 | list→info→run；注册后新会话复用 | 工具可发现、参数和结果可追溯 |
| E 故障与历史 | 超时、断流、上限、跨话题追问 | 已得结果保留，最终状态不冒充成功 |

| J 公开证据追问 | 首页、后续页、事件、公司词、游标与不适用方法 | 全部已分析事件可到达；页映射不明时不猜；完整 F01 与账户字段不外发 |

## 执行与证据

| 事项 | 要求 |
| --- | --- |
| 隔离 | 使用独立会话与股票状态目录；不新建第二聊天库 |
| 自动测试 | 聊天侧按仓库 AGENTS.md 的 unittest 命令（当前 222 项通过、1 项跳过）；股票侧按其对应测试集（当前 772 项通过） |
| 股票侧测试命令 | `cd D:\Stock_Agent_Workspace` 后 `.\.venv-paper\Scripts\python.exe -m pytest tests -q --basetemp=D:\Stock_Agent_Workspace\simulation\pytest-tmp`。**必须带 `--basetemp=`**：默认 `%TEMP%\pytest-of-Administrator` 权限损坏，会产出数百个 `PermissionError` 假失败，不是代码缺陷 |
| 真实模型/接口 | 只在需要核实路由或外部行为时使用；记录次数、预算和结果 |
| 体验 | 至少验证一条同入口用户路径；自动测试不替代可读性验收 |
| 记录 | 在 docs/记录/ 新建日期主题表，写操作、预期、实际、证据和未完成项 |
| 判定 | 分开写“代码检查”“在线实测”“用户验收”；失败/跳过不得计为通过 |
| 生效范围 | 改了 `skills/**`（容器内代码）必须 `.\scripts\start-daily.ps1 -Build` 重建镜像，只重启后端不算验证；改了 `core/**`/`bff/**` 需重启后端；改了 `apps/web/**` 需重新构建并刷新。三类都不生效时的表现见 AGENTS.md |
| 工具面自查 | 验证工具改动前，先确认运行中的容器真的换了代码：`Invoke-RestMethod http://127.0.0.1:9101/openapi.json`（skill-files）看请求字段 |

具体示例消息、边界案例和原始矩阵见[原稿](./记录/回归验证指南-原稿.md)。

## 多目录、多会话工作区回归（R2）

所有在线验证仍经根目录启动.bat；使用独立验收会话和专用目录，不另建会话库。

| 场景 | 预期 |
| --- | --- |
| 一个工作区创建两个会话 | 共享目录；消息、模型、方法、草稿与附件独立，刷新后恢复 |
| 搜索只命中正文 | 显示所属工作区及命中摘要，不切换或重载当前会话 |
| C/D 盘两个目录 | 原地上传、预览、下载、重命名、新建目录；无源目录复制 |
| 同工作区及目录重叠 | 409 携带执行会话，不受理冲突消息；不同目录可并行 |
| 运行中删会话、删消息、切版本 | 409；停止或断开后释放执行锁 |
| 新旧工作区隔离 | 文件工具与 Shell/Python 均不可访问未添加目录；默认组遮蔽其他组托管目录 |
| 凭据与网络隔离 | 外来工具凭据返回 403；容器不能无页面凭据读取 BFF 会话；各组网络不同，私密凭据不能出现在公开响应 |
| NTFS junction 与失联 | 文件路径及脚本预检拒绝链接越界；失联根显示不可用、不回退到托管目录，恢复原目录后可用 |
| 目录移除后重新添加 | 稳定目录 ID 恢复；历史链接仍指向同一源目录 |
| 云端授权 | 关闭读取、只读、读写三态；增加目录到已授权工作区需要确认 |
| 配置失败与重启 | 保留有效配置和待生效意图；激活前检查容器 ID/版本；主机目录写入受限通过文件容器 |
| 回收站与脚本 | 各根目录删除恢复、冲突/移除根拒绝；默认主要目录执行及跨根目录读写 |
| 布局与报告 | 六档宽度及 360px，无横向越界；报告卡→文档→阅读器→返回文档；输入法、键盘与 reduced-motion |
| 完整退出 | 股票收尾后停止全部工作区容器组、聊天后端与启动器 |

本次真实 BFF、容器、并发、断点与显式退出证据，以及输入法、原型对照和关闭全部页面的剩余人工验收，分开记录于 [R2 记录](./记录/2026-10-07-多目录多会话工作区完善.md)。
