# docs 目录 AI 规则

编辑本目录前先读[文档记录简则](./文档记录简则.md)。根目录 AGENTS.md 的唯一入口、唯一数据与服务生命周期规则优先。

| 必须遵守 | 处理方式 |
| --- | --- |
| 进度只认股票仓库 | IN 系列状态以股票仓库 docs/计划.md 为准；本目录不复制第二份完成清单 |
| 文档归属 | 正式计划仅记阶段和实现状态，说明及契约放 docs/；临时排错和实施记录放根目录 temp/ |
| 清理范围 | 过时实施流水可删除；业务数据、原件、回执和测试夹具保留 |
| 链接与入口 | 修改后检查相对链接；用户入口只能写根目录 启动.bat |
