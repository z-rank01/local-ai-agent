# 股票能力接入

| 新增接口 | 职责边界 |
| --- | --- |
| `/api/internal/research-generation` | 股票冻结 C01/C02/C03/C04 提示词、契约及公开材料；BFF 供应商请求逐项保留参数并返回结束原因、响应 ID 与用量；C05/D01 保持原通路 |
| `context_evidence_read` | 本会话已授权历史的分页回读，复用 conversations.db；不能读取其他会话、私有附件或未授权投影 |
| 步骤检查点 | 股票工作进程退出时保存新只读研究步骤；BFF 沿用原退出控制接口；事件成功回执保留结束原因与响应 ID，已知拒绝和 UNKNOWN 分开 |

本文件只维护聊天侧与股票侧的分工。IN 系列当前状态由股票仓库 docs/计划.md 统一维护；早期需求、逐批实现和验收记录见[详细原稿](./记录/股票能力接入-原稿.md)。

## 能力与归属

| 能力 | 聊天仓库负责 | 股票仓库负责 |
| --- | --- | --- |
| 用户入口 | 唯一 Web、会话、模型选择和技能开关 | 不另开聊天入口 |
| 股票工具 | 注册与展示、可信会话身份、模型可见投影 | 票据、引用、预算、幂等和业务规则 |
| 研究闭环 | 提交、查询、读取、取消、恢复的聊天交互 | 队列、专业职责、证据与报告 |
| 账户与订单 | 展示已授权投影和本地附件 | 账本、人工确认、事务与审计 |
| 数据 | 不从聊天容器直接取股票源 | 白名单工作进程、超时、缓存和失败关闭 |
| 方法论 | 标准技能格式和按需加载 | 金融内容、数据口径与专业角色 |
| 简报追问 | 股票卡片内会话方法单选、授权报告页正文、公开证据读取与本地附件展示 | 公开旧版跨会话查找、原文位置、页映射、冻结方法版本与任务回执 |
| 主题机会 | `stock_theme_research_submit/find` 与既有报告读取；结构化公开搜索线索 | C01/C02 → 新任务自动 C03；公司财务、同行、条件估值及缺口，候选与交易门禁独立 |
| 跨日观点 | `stock_track_follow/find/read/ignore` 与复查任务查找；安全会话引用 | 关注状态、不可改写的研究版本、C04 公开证据复查与来源校验 |
| 对话续行 | 股票工具首次调用后开放十分钟新步骤；会话保留结果、附件和游标 | 网关不设新票据固定步数，旧票据沿用冻结规则；来源与交易门禁不变 |
| 公司原文与专业续行 | 公告线索限定该证券公告详情页，只读研究不自动写通用记忆 | 完整公司公告目录发现财报；同一发布版本C03明确截断提高额度，独占重启续行，未知调用不重发 |
| 估值追问 | 区分原文、程序值和AI假设；旧文字冲突按待核说明 | 当前倍数与情景金额由程序核对；同行候选先核验，历史公开投影复核不改写旧任务或报告 |
| 部分研究成果 | 本地附件与公开证据按需读取，不能将任务归档当作完整研究 | 早期综合经保存回执绑定原文/财报，标明后续综合缺口；[本轮记录](./记录/2026-10-09-IN4.20-原文格式发布与部分成果读取.md) |

## 已有接口与边界

| 阶段 | 聊天侧能力 | 不可混淆 |
| --- | --- | --- |
| IN1 | 模型路由、工具、skills、编辑和历史 | 技能可发现不等于外部脚本可运行 |
| IN2 | 账户、研究查找、报告读取 | 完整报告本地直出，不进模型历史 |
| IN3 | 研究受理、停止和受控恢复 | QUEUED 不等于完成；停止生成不等于取消研究 |
| N2 | 股票技能开关、恢复与任务执行控制 | 恢复补采不等于离线期间已实时监控 |
| IN4 | 研究与风控工具、简报提交/查找/逐页读取/明确续读；后台分析模型独立选择；BFF 直连云端模型并提供只读公开搜索线索 | 全文分块、截断续行、跨块综合、原文核验与研究回执；B04 真实持仓链和新简报质量仍逐项验收 |

云端明确截断时返回原始输出、用量与模型参数，股票侧缩小正文块续行；网络结果不明不自动重发。公开搜索仅由可信证券身份生成查询，搜索摘要不作为研究事实。[本轮记录](./记录/2026-09-27-IN4.19-续行与公开搜索.md)。

IN4.5事件云端复测复用原内部分析接口，可显式冻结Qwen3.8-Flash的思考开关、预算、温度和输出额度；未知参数拒绝，原请求兼容。公开材料校验覆盖巨潮核查PDF及严格脱敏的公告目录超时回执，拒绝账户字段和任意错误正文。模型选择仅作用于本轮回放，不改日常模型或Dify职责；技术验证与比较结论分开记录，详见[接口记录](./记录/2026-10-10-IN4.5-Qwen事件分析接口.md)。

简报公开证据可按任务引用、事件或报告页逐段读取；页内事件只有唯一映射时才作确定说明。方法选择保存在当前会话，只影响后续解释和明确提交的新研究任务；自动日程与旧报告不变。[接入记录](./记录/2026-09-27-IN4.19-证据与方法桥接.md)。

IN4.5 增加三份股票侧候选：业绩解读（C03）、政策传导（C01/C02）、事件解读（market_brief）。聊天复用既有动态查询和会话单选，接口测试覆盖三项、非法ID拒绝与会话隔离；前端源码未改。股票侧当前进度统一见其 `docs/计划.md`，发布和人工初始化证据见 `docs/记录/2026-10-10-IN4.5-新版发布复核与人工初始化待办.md`，旧调用事故另存记录且不自动重发UNKNOWN。

同一启动器的 `-AcceptanceState` 核对已保存独立目录、技能开启、worker=false及旧栈监听；它不另建入口、账户或数据库，不受调用预算策略放宽影响。

用户已撤销IN4.5固定累计调用上限与反复预算确认。六场景×两方法×三次是有效样本设计，准备和修正调用另外记录；已授权范围内必要补测不按累计次数再次确认。UNKNOWN/pending及同材料场景隔离，其他场景只有可信后端核验服务健康与无依赖后继续；不以新ID/批次绕过未知请求，保留有限修正、跨批次执行锁、旧审计只读及质量门禁。股票侧另行区分已知输出校验失败与真实UNKNOWN，只有完整可核验结果用于模型参数比较，事件回放复用生产引文切片且不缩减全文。[原规则检查记录](./记录/2026-10-10-IN4.5-调用限制文档调整.md)；发布、首次真实回放及修复证据见股票仓库 `docs/记录/2026-10-10-IN4.5-发布复核与首次真实回放修复.md`，当前进度统一查其 `docs/计划.md`，技术回执不等于分析质量验收通过。

新主题任务自动接 C03；新指定公司研究直接进入 C03，复用同一财务和估值计算，不要求先发现产业趋势；运行器从任务记录核对探索路线，该路线仅用于 C03 分析，不进入候选或交易卡片。现有公开证据工具支持主题任务，公司原文、财报字段、程序计算和 AI 假设分别标注，证据摘录与事实引文同步分页；TTM/单季可按来源字段追问。公司研究报告用人可读财务、同行和估值表，不附整份原始JSON；授权报告页区分市场简报与本地研究，正文授权边界不变。旧任务不补写新字段；真实模型与 Web 质量验收仍待完成。[本批记录](./记录/2026-10-08-IN4.20-公司研究追问.md)。

主题任务引用已完成简报；搜索关键词先由股票侧对公开原文核对，行业背景不可当作公司受益证据。[工具记录](./记录/2026-09-27-IN4.19-主题工具桥接.md)。

跨日跟踪只接收用户明确关注的已完成主题研究对象。日程复查由股票侧记录；只有核对到相关新原文并形成有效判断才新增观点版本。聊天模型可读取最近复查状态、公开论点、逐字证据和缺口；旧观点与完整本地报告仍保存在股票侧。[接入记录](./记录/2026-09-27-IN4.21-跨日跟踪桥接.md)。

## 固定约束

| 项目 | 要求 |
| --- | --- |
| 入口 | 根目录 启动.bat → scripts/start-daily.ps1；BFF 同源托管 Web |
| 数据 | 会话库、工作区和模型账本各一份；隔离验收用独立会话与股票状态目录 |
| 开关 | 股票/联网搜索能力经持久化技能开关控制，工具注册随生命周期翻转 |
| 身份 | 模型不能自填 actor、scope、票据或订单确认 |
| 隐私 | 完整 F01、私有材料与密钥不进入云端模型历史或记忆；市场简报只投影已核对的公开正文证据 |
| 退出 | 页面“退出”或关闭页面；先股票收尾，再停容器和聊天服务 |
| 本地金融技能 | 可按需试用现有参考文件；脚本依赖、数据口径与执行隔离逐项验证 |

字段级股票契约看股票仓库 docs/工具网关.md；日常操作看[日常运行指南](./日常运行指南.md)。

只读研究验收沿用工作台的任务执行开关：勾选“仅执行主动提交的只读研究”后启动同一工作进程，暂停日常调度及账户任务领取；停止、退出和恢复仍走原入口。该设置不会自动修改账户规则。
