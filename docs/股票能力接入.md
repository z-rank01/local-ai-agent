# 股票能力接入

本文件只维护聊天侧与股票侧的分工。IN 系列当前状态由股票仓库 docs/计划.md 统一维护；早期需求、逐批实现和验收记录见[详细原稿](./记录/股票能力接入-原稿.md)。

## 能力与归属

| 能力 | 聊天仓库负责 | 股票仓库负责 |
| --- | --- | --- |
| 用户入口 | 唯一 Web、会话、模型选择和技能开关 | 不另开聊天入口 |
| 股票工具 | 注册与展示、可信会话身份、模型可见投影 | 票据、引用、预算、幂等和业务规则 |
| 研究闭环 | 提交、查询、读取、取消、恢复的聊天交互 | 队列、专业职责、证据与报告 |
| 账户与订单 | 展示已授权投影和本地附件 | 账本、人工确认、事务与审计 |
| 数据 | 不从聊天容器直接取股票源 | 白名单工作进程、超时、缓存和失败关闭 |
| 方法论 | 标准技能格式和按需加载 | 金融内容、数据口径与专业角色 |

## 已有接口与边界

| 阶段 | 聊天侧能力 | 不可混淆 |
| --- | --- | --- |
| IN1 | 模型路由、工具、skills、编辑和历史 | 技能可发现不等于外部脚本可运行 |
| IN2 | 账户、研究查找、报告读取 | 完整报告本地直出，不进模型历史 |
| IN3 | 研究受理、停止和受控恢复 | QUEUED 不等于完成；停止生成不等于取消研究 |
| N2 | 股票技能开关、恢复与任务执行控制 | 恢复补采不等于离线期间已实时监控 |
| IN4 | Agent Skills 格式、部分专业与风控接入；空仓简报通过聊天工具提交/查找与读取；股票技能面板从对话模型目录选择后台分析模型，BFF 使用既有密钥直连兼容云端 API | 每日简报逐事件读取可解析全文、分块校验引文；按需给对话模型公开证据。B04 真实持仓链、主动发现及更多数据能力仍逐项验收 |

云端事件分析的输出上限可在静态模型目录按型号配置；动态发现型号使用提供方默认值。达到输出上限会报告失败，股票侧保留原调用记录。见[本次通道记录](./记录/2026-09-27-IN4.19-质量优先云端通道.md)。

## 固定约束

| 项目 | 要求 |
| --- | --- |
| 入口 | 根目录 启动.bat → scripts/start-daily.ps1；BFF 同源托管 Web |
| 数据 | 会话库、工作区和模型账本各一份；隔离验收用独立会话与股票状态目录 |
| 开关 | 股票/联网搜索能力经持久化技能开关控制，工具注册随生命周期翻转 |
| 身份 | 模型不能自填 actor、scope、票据或订单确认 |
| 隐私 | 完整 F01、私有材料与密钥不进入云端模型历史或记忆；市场简报只投影已核对的公开正文证据 |
| 退出 | 页面“退出”或关闭页面；先股票收尾，再停容器和聊天服务 |
| 本地金融技能 | 可按需试用现有参考文件；脚本依赖、数据口径与执行隔离逐项验证 |

字段级股票契约看股票仓库 docs/工具网关.md；日常操作看[日常运行指南](./日常运行指南.md)。
